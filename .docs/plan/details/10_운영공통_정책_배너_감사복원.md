# D10. 운영 공통 · 동적 정책 · 배너 · 감사로그 · 원클릭 복원 (`10_운영공통_정책_배너_감사복원`)

> **상태**: As-Built 확정 (실구현 코드 100% 동기화) | **Wave**: Wave 1  
> **소유 테이블**: 4개 (`MUTABLE` 2 + `APPEND_ONLY` 2) | **담당 화면**: 3개 (`SCR-A02`, `SCR-A30`, `SCR-A31`)  
> **핵심 코드**: `packages/db/src/schema/10_operations.ts` · `apps/web/src/04_services/shared/{policyService,auditService}.ts` · `apps/web/src/03_actions/admin/adminTrainerOpsActions.ts`

## 1. PostgreSQL 18 물리 테이블 명세 (4개)

### 1.1 `audit_logs` `[APPEND_ONLY]` — 전역 감사로그
- `actor_type` (`ADMIN \| USER \| SYSTEM`), `actor_id`, `action` (`admin.login`, `entity.soft_delete`, `entity.restore`, `policy.update`, `order.shipment_update` 등), `entity`, `entity_id`, `before_data` (`JSONB`), `after_data` (`JSONB`), `ip_address`, `user_agent`, `created_at`.
- **인덱스**: `idx_audit_logs_entity`, `idx_audit_logs_actor_created`, `idx_audit_logs_action`.

### 1.2 `banners` `[MUTABLE]`
- `title`, `subtitle`, `image_url`, `link_url`, `placement` (`HOME \| SHOP_HOME \| NOTICE`), `accent_token` (`brand-lime` 등), `start_at`, `end_at`, `sort_order`, `is_active`. (`idx_banners_placement_active`)

### 1.3 `policy_configs` `[MUTABLE]` — 동적 비즈니스 정책 단일 원천 (`GM-011`)
- `key` (`VARCHAR(100)`, `uq_policy_configs_key_active`), `value` (`JSONB`), `description`.
- **원칙**: 코드 내부 정책 Fallback 상수 `0%`. `policyService.ts` (`getPolicyNumber`, `getPolicyBoolean`, `getPolicyString`, `getRechargePackagesPolicy`)는 필수 키 누락 시 즉시 명시적 에러(Fail-Fast)를 발생시킴.
- **시드 17개 키**: `point.watch`, `point.practice`, `point.quiz`, `point.bonus.unit`, `point.bonus.course`, `point.daily_earn_cap`, `point.expire_days`, `watch.complete_percent`, `quiz.pass_percent`, `level_test.pass_score_pct`, `level_test.bonus_enabled`, `level_test.bonus_points`, `inquiry.price`, `inquiry.sla_hours`, `inquiry.assignment_mode`, `settlement.commission_rate`, `recharge.packages`.

### 1.4 `policy_config_histories` `[APPEND_ONLY]` — 정책 변경 이력
- `policy_config_id` (FK `policy_configs.id`), `key`, `old_value` (`JSONB`), `new_value` (`JSONB`), `admin_id`, `created_at`.
