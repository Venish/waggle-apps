# D08. 훈련사 · 비동기 영상 Q&A · 월 정산 (`08_훈련사_영상QA_월정산`)

> **상태**: As-Built 확정 (실구현 코드 100% 동기화) | **Wave**: Wave 2  
> **소유 테이블**: 4개 (`MUTABLE` 4) | **담당 화면**: 9개 (`SCR-U31~U33`, `SCR-A23~A28`)  
> **핵심 코드**: `packages/db/src/schema/08_trainer_qa.ts` · `apps/web/src/03_actions/{web/inquiryNoticeActions,admin/adminTrainerOpsActions}.ts` · `apps/web/src/app/api/cron/inquiry-sla/route.ts`

---

## 1. PostgreSQL 18 물리 테이블 명세 (4개)

### 1.1 `trainers` `[MUTABLE]`
- `admin_id` (FK `admins.id` NULL, `uq_trainers_admin_active`), `name`, `bio`, `profile_image`, `career_years`, `is_active`.

### 1.2 `trainer_tags` `[MUTABLE]`
- `trainer_id` (FK `trainers.id`), `tag_id` (FK `tags.id`). (`uq_trainer_tags_active`)

### 1.3 `inquiries` `[MUTABLE]` — 1:1 비동기 영상 Q&A
- `user_id` (FK `users.id`), `dog_id` (FK `dogs.id` NULL), `trainer_id` (FK `trainers.id` NULL), `specialty_tag_id` (FK `tags.id` NULL), `video_url`, `question`, `paid_points` (`BIGINT`, 접수 시점 `policy_configs['inquiry.price']` 스냅샷), `status` (`PENDING \| ASSIGNED \| ANSWERED \| EXPIRED \| CANCELLED`), `assigned_at`, `sla_due_at` (`TIMESTAMPTZ(3)`, 접수 + `inquiry.sla_hours`), `answer_text`, `answer_video_url`, `answered_at`, `refunded_at`, `rating`, `rating_comment`.
- **인덱스**: `idx_inquiries_user_created`, `idx_inquiries_trainer_status`, `idx_inquiries_status_sla`.

### 1.4 `trainer_settlements` `[MUTABLE]` — 훈련사 월 정산
- `trainer_id` (FK `trainers.id`), `period_ym` (`VARCHAR(7)`, 예: `2026-11`), `total_inquiries`, `total_points` (`BIGINT`), `commission_rate` (`NUMERIC(5,4)`), `payout_amount` (`BIGINT`), `status` (`DRAFT \| CONFIRMED \| PAID`), `confirmed_at`, `paid_at`, `memo`.
- **Partial Unique**: `uq_trainer_settlements_active (trainer_id, period_ym) WHERE is_deleted = false`

## 2. 기능 · SLA 배치 · RBAC 계약

- **동적 정책 키 (`policy_configs`)**: `inquiry.price` (1500), `inquiry.sla_hours` (48), `inquiry.assignment_mode` (`MANUAL_RECOMMEND`), `settlement.commission_rate` (0.7).

| 기능 ID | 기능명 | 구현 진입점 | ACID / RBAC 계약 |
| :---: | :--- | :--- | :--- |
| `D08-F01` | 영상 Q&A 접수 & 포인트 선차감 | `createInquiryAction` (`03_actions/web/inquiryNoticeActions.ts`) + `POST /api/upload` | 단일 `db.transaction`: `inquiry.price` 조회 ➔ `spendPointsFifoTx` 차감 ➔ `inquiries` INSERT (`slaDueAt = now + inquiry.sla_hours`) |
| `D08-F02` | 배정 전 사용자 취소 & 전액 환불 | `cancelInquiryAction` | `PENDING` 상태 본인 문의만 취소 허용; 원본 `paidPoints` 전액 환불 |
| `D08-F03` | 48h SLA 초과 자동 만료 환불 배치 | `POST /api/cron/inquiry-sla` | `x-cron-secret` 검증 ➔ `status IN ('PENDING','ASSIGNED') AND sla_due_at < NOW()` 건을 `EXPIRED` 전이 + 원본 `paidPoints` 환불 + `INQUIRY_REFUNDED` 알림 적재 |
| `D08-F04` | 관리자 훈련사 배정 & 프로필 등록 | `adminAssignInquiryAction`, `adminCreateTrainerAction` (`03_actions/admin/adminTrainerOpsActions.ts`) | `ADMIN` RBAC, 배정 시 `status='ASSIGNED'`, `assigned_at` 기록 |
| `D08-F05` | 훈련사 솔루션 답변 제출 | `trainerSubmitAnswerAction` | `TRAINER`/`ADMIN` RBAC; `status='ANSWERED'`, `answered_at` 기록 + 보호자 `INQUIRY_ANSWERED` 알림 발송 |
| `D08-F06` | 월 정산 산출 & 상태 전이 | `adminGenerateMonthlySettlementAction`, `adminUpdateSettlementStatusAction` | 해당 월 `ANSWERED` 건의 `SUM(paid_points) × settlement.commission_rate` 산출 (`DRAFT → CONFIRMED → PAID`) |
