## 1. PostgreSQL 18 물리 테이블 명세 (7개)

### 1.1 `breeds` `[MUTABLE]` — 견종 마스터
- `code` (`VARCHAR(60)`), `name_ko` (`VARCHAR(80)`), `name_en` (`VARCHAR(100)`), `default_size` (`SMALL \| MEDIUM \| LARGE`).
- **Partial Unique**: `uq_breeds_code_active (code) WHERE is_deleted = false`
- **삭제 차단**: 활성 `dogs.breed_id` 참조 존재 시 `REFERENCE_BLOCKED` 원천 차단.

### 1.2 `dogs` `[MUTABLE]` — 반려견 프로필
- `user_id` (FK `users.id`), `name`, `birth_date` (`DATE`), `breed_id` (FK `breeds.id` NULL), `size_class` (`SMALL \| MEDIUM \| LARGE`), `gender` (`MALE \| FEMALE`), `neutered` (`BOOLEAN`), `weight_kg` (`NUMERIC(5,2)`), `region`, `profile_image`, `grade` (`INTEGER DEFAULT 1`), `is_primary` (`BOOLEAN DEFAULT false`).
- **인덱스**: `idx_dogs_user_active (user_id, is_deleted)`
- **소유권/대표견 불변식**: 세션 `userId` 본인 소유만 수정·삭제 가능. 대표견 삭제 시 잔여 활성 반려견 중 첫 번째로 `is_primary` 자동 승계(단독 마지막 반려견 삭제 시 안내 차단).

### 1.3 `anniversaries` `[MUTABLE]`
- `dog_id` (FK `dogs.id`), `label` (`VARCHAR(60)`), `date` (`DATE`). (`idx_anniversaries_dog`)

### 1.4 `daily_entries` `[MUTABLE]` — 일자별 데일리 기록
- `dog_id` (FK `dogs.id`), `entry_date` (`DATE`), `walked` (`BOOLEAN DEFAULT false`), `memo` (`TEXT`).
- **Partial Unique**: `uq_daily_entries_dog_date_active (dog_id, entry_date) WHERE is_deleted = false`
- **도메인 원칙**: 일상기록은 순수 보조 기록으로 포인트 적립과 연동하지 않음.

### 1.5 `daily_entry_stickers` `[MUTABLE]` — 일상 스티커/사진
- `entry_id` (FK `daily_entries.id`), `kind` (`POOP \| MEAL \| MEDICINE \| HOSPITAL \| WALK \| CUSTOM`), `note`, `photo_url`. (`idx_daily_stickers_entry`)

### 1.6 `common_codes` `[MUTABLE]` — 공통코드 마스터
- `code_group` (`VACCINE_TYPE` 등), `code`, `code_kor_name`, `description`, `sort_order`, `is_active`, `extra` (`JSONB`, 예: `{ intervalDays, isMandatory }`).
- **Partial Unique**: `uq_common_codes_group_code_active (code_group, code) WHERE is_deleted = false`
- **삭제 차단**: 활성 `vaccination_records.vaccine_id` 참조 존재 시 `REFERENCE_BLOCKED` 원천 차단.

### 1.7 `vaccination_records` `[MUTABLE]` — 예방접종 이력
- `dog_id` (FK `dogs.id`), `vaccine_id` (FK `common_codes.id`), `administered_at` (`TIMESTAMPTZ(3)`), `next_due_at` (`TIMESTAMPTZ(3) NULL`), `hospital`, `memo`. (`idx_vaccination_dog_due`)
