## 1. PostgreSQL 18 물리 테이블 명세 (3개)

### 1.1 `daily_goals` `[MUTABLE]`
- `user_id` (FK `users.id`), `daily_lesson_goal` (`INTEGER NOT NULL DEFAULT 1`, 1~5), `reminder_enabled` (`BOOLEAN DEFAULT true`), `reminder_time` (`VARCHAR(10) DEFAULT '20:00'`).
- **Partial Unique**: `uq_daily_goals_user_active (user_id) WHERE is_deleted = false`

### 1.2 `badges` `[MUTABLE]`
- `code` (`VARCHAR(80)`), `kind` (`COURSE_COMPLETE \| UNIT_COMPLETE \| MILESTONE \| EVENT`), `name` (`VARCHAR(100)`), `icon_name` (`VARCHAR(60) DEFAULT 'Award'`, Lucide 아이콘명), `description`.
- **Partial Unique**: `uq_badges_code_active (code) WHERE is_deleted = false`
- **시드 배지 6종**: `FIRST_LESSON`, `THREE_LESSONS`, `FIRST_UNIT`, `FIRST_COURSE`, `PERFECT_QUIZ`, `SEVEN_DAY_STREAK`.

### 1.3 `dog_badges` `[MUTABLE]`
- `dog_id` (FK `dogs.id`), `badge_id` (FK `badges.id`), `earned_at` (`TIMESTAMPTZ(3)`).
- **Partial Unique**: `uq_dog_badges_active (dog_id, badge_id) WHERE is_deleted = false` (동일 배지 중복 지급 원천 차단).

## 2. 기능 · 계산식 · 진입점

- **학년 승급 공식 (`calcGradeFromLessonCount` / `formatGradeLabel` + `policy_configs.grade.tiers`)**: 반려견별 누적 완료 레슨 수(`lesson_progresses.completed_at IS NOT NULL`)와 DB `policy_configs`의 `grade.tiers`(1~5학년 명칭 및 필요 레슨 수, 기본 `0/3/8/15/25`, `/admin/education` 상단 일괄 정책 패널에서 무배포 조정 가능)를 기준으로 승급 산출하며, 정책 상향 시 기존 달성 학년은 강등 방지(`Math.max`)로 보호.
- **리마인드 배치 연동**: `POST /api/cron/daily-reminder`가 `daily_goals.reminder_enabled=true` 회원 중 당일 목표 미달성 보호자에게 알림 적재.

| 기능 ID | 기능명 | 구현 진입점 | 핵심 규칙 |
