# D09. 알림 · 푸시 · Cloud Scheduler 배치 (`09_알림_푸시_배치`)

> **상태**: As-Built 확정 (실구현 코드 100% 동기화) | **Wave**: Wave 2  
> **소유 테이블**: 2개 (`MUTABLE` 1 + `APPEND_ONLY` 1) | **담당 화면**: 3개 (`SCR-U37`, `SCR-U38`, `SCR-A29`)  
> **핵심 코드**: `packages/db/src/schema/09_notifications.ts` · `apps/web/src/00_lib/adapters.ts` · `apps/web/src/app/api/cron/{expire-points,inquiry-sla,daily-reminder}/route.ts`

---

## 1. PostgreSQL 18 물리 테이블 명세 (2개)

### 1.1 `notification_templates` `[MUTABLE]`
- `code` (`VARCHAR(80)`, `uq_notification_templates_code_active`), `title` (`VARCHAR(150)`), `body` (`TEXT`), `data` (`JSONB`).
- **시드 템플릿 4종**: `DAILY_GOAL_REMINDER`, `INQUIRY_ANSWERED`, `INQUIRY_REFUNDED`, `POINT_EXPIRE_SOON`.

### 1.2 `notifications` `[APPEND_ONLY]` — 인앱 알림함
- `user_id` (FK `users.id`), `kind` (`notification_kind` ENUM 11종: `COURSE_RECOMMEND`, `DAILY_GOAL_REMINDER`, `POINT_EARNED`, `POINT_EXPIRE_SOON`, `INQUIRY_ANSWERED`, `INQUIRY_REFUNDED`, `BADGE_EARNED`, `VACCINE_DUE`, `ORDER_UPDATE`, `NOTICE`, `CUSTOM`), `title`, `body`, `deep_link`, `data` (`JSONB`), `is_read` (`BOOLEAN DEFAULT false`), `read_at` (`TIMESTAMPTZ(3) NULL`), `created_by`, `created_at`.
- **예외 규약**: `APPEND_ONLY` 불변 로그이나, 수신 확인(`is_read = true`, `read_at = NOW()`) 단방향 갱신만 허용.

## 2. 알림 발송 · Cloud Scheduler 배치 규격

> 별도 Redis/BullMQ 워커 서버 없이, 모든 정기 배치는 **Firebase/GCP Cloud Scheduler → `POST /api/cron/*`** 직통 호출 + `x-cron-secret` (`CRON_SECRET` 환경변수 일치) 검증으로 완결한다.

| 기능 ID | 기능명 | 구현 진입점 | 동작 / 보안 계약 |
| :---: | :--- | :--- | :--- |
| `D09-F01` | 보호자 알림 읽음 처리 | `markNotificationReadAction` (`03_actions/web/inquiryNoticeActions.ts`) | `session.userId` 소유권 조건부 `UPDATE notifications SET is_read=true, read_at=NOW()` |
| `D09-F02` | 관리자 수동 알림 발송 & 템플릿 편집 | `adminSendNotificationAction`, `adminUpdateTemplateAction` (`03_actions/admin/adminTrainerOpsActions.ts`) | 특정 `targetUserId` 또는 전체 활성 회원 대상 `notifications` 적재 + `sendPushNotificationAdapter` (Mock FCM 로그) 호출 |
| `D09-F03` | 데일리 목표 리마인드 배치 | `POST /api/cron/daily-reminder` | `x-cron-secret` 불일치 시 `401`; 당일 목표 미달성 & `education_push_opt_in=true` 회원에게 `DAILY_GOAL_REMINDER` 적재 |
| `D09-F04` | 일일 포인트 FIFO 소멸 배치 | `POST /api/cron/expire-points` | `x-cron-secret` 검증; 만료 도래 원장 소멸 + 알림 적재 |
| `D09-F05` | Q&A 48h SLA 초과 환불 배치 | `POST /api/cron/inquiry-sla` | `x-cron-secret` 검증; SLA 초과 Q&A `EXPIRED` + 원본 포인트 환불 + `INQUIRY_REFUNDED` 알림 |
