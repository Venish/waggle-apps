## 1. PostgreSQL 18 물리 테이블 명세 (8개)

### 1.1 `survey_questions` `[MUTABLE]`
- `code` (`VARCHAR(60)`), `text` (`TEXT`), `allow_multiple` (`BOOLEAN DEFAULT false`), `sort_order`, `is_active`.
- **Partial Unique**: `uq_survey_questions_code_active (code) WHERE is_deleted = false`

### 1.2 `survey_answers` `[MUTABLE]`
- `question_id` (FK `survey_questions.id`), `text` (`VARCHAR(200)`), `sort_order`, `is_active`. (`idx_survey_answers_question`)

### 1.3 `survey_responses` `[MUTABLE]`
- `dog_id` (FK `dogs.id`), `answer_id` (FK `survey_answers.id`).
- **Partial Unique**: `uq_survey_responses_dog_answer_active (dog_id, answer_id) WHERE is_deleted = false`

### 1.4 `tags` `[MUTABLE]`
- `code` (`VARCHAR(60)`), `name` (`VARCHAR(80)`), `category` (`AGE \| EXPERIENCE \| PROBLEM \| GOAL \| ENV \| SOCIAL \| SPECIALTY \| ETC`), `is_active`.
- **Partial Unique**: `uq_tags_code_active (code) WHERE is_deleted = false`

### 1.5 `course_tags` `[MUTABLE]`
- `course_id` (FK `courses.id`), `tag_id` (FK `tags.id`), `weight` (`INTEGER DEFAULT 1`).
- **Partial Unique**: `uq_course_tags_active (course_id, tag_id) WHERE is_deleted = false`

### 1.6 `answer_tags` `[MUTABLE]`
- `answer_id` (FK `survey_answers.id`), `tag_id` (FK `tags.id`), `weight` (`INTEGER DEFAULT 1`).
- **Partial Unique**: `uq_answer_tags_active (answer_id, tag_id) WHERE is_deleted = false`

### 1.7 `level_tests` `[MUTABLE]`
- `course_id` (FK `courses.id`), `title`, `skip_to_unit_order` (`INTEGER DEFAULT 1`), `questions` (`JSONB`: `{ text, choices, answerIndex, explanation }[]`), `pass_percent_override` (`INTEGER NULL`), `is_active`.

### 1.8 `level_test_attempts` `[APPEND_ONLY]`
- `level_test_id` (FK `level_tests.id`), `dog_id` (FK `dogs.id`), `answers` (`JSONB`: `number[]`), `score`, `total`, `passed` (`BOOLEAN`), `created_by`, `created_at`.

## 2. 순수 매칭 엔진 · 기능 · 진입점

- **순수 계산식 (`packages/types/src/domain/matching-fifo.ts`)**: `scoreCourses(selectedTagWeights, courseTagVectors)` — 설문 응답 태그 + 반려견 월령 자동 태그(`resolveAgeTag`)와 코스-태그 가중치 벡터의 내적(Dot Product)으로 1~3순위 맞춤 커리큘럼 점수 산출.
- **동적 정책 키 (`policy_configs`)**: `level_test.pass_score_pct`, `level_test.bonus_enabled`, `level_test.bonus_points`.
