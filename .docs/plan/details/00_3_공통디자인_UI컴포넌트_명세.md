## 1. 물리 격리 & 전 영역 공통 가드레일

1. **CSS · 폴더 100% 물리 분리**:
   - `(www)` · `(mobile)` Root Layout은 `styles/web.css` 및 `components/web/*`, `01_store/web/*`만 import.
   - `(admin)` Root Layout은 `styles/admin.css` 및 `components/admin/*`, `01_store/admin/*`만 import (상호 교차 import 0건, 추후 `apps/admin` 1:1 분리 대비).
2. **타이포 · 아이콘 · 이모지**:
   - 전 영역 셀프호스팅 `PretendardVariable.woff2` (`next/font/local`) 통일, 사용자 영역 `body` 전역 `word-break: keep-all; overflow-wrap: break-word;` 적용(한글 어절 줄바꿈 보장), 날짜는 `formatDateDot`/`formatDateTimeDot` 점(`.`) 포맷 통일.
   - 전 화면 유니코드 이모지 0건, `lucide-react` 단색 SVG · 하단 5탭 전용 SVG · `@repo/ui` 테마 연동 브랜드 SVG(`WaggleMark`, `WaggleWordmark`)만 사용.
3. **폼 · 알림 · 동기 락 규약**:
   - 전 폼 `<form noValidate>` 적용, 브라우저 기본 `window.alert()` 0건, Zustand 전역 Alert(`closeOnOverlayClick={false}`, `closeOnEscape={false}`, `onConfirm` 단발 실행 보장) 통일.
   - 모든 변경/결제/취소/후기 버튼에 `02_hooks/useSubmitLock.ts` (`useRef` 0ms 동기 연타 가드) 적용.
4. **선언 토큰 전용**: 임의 `text-[...]` 및 레거시 다색 파스텔 클래스 0건, 각 영역 `@theme` 선언 `rem` 토큰 및 `.waggle-prose`/`.admin-prose`만 사용.
