## 1. PostgreSQL 18 물리 테이블 명세 (7개)

> 전 테이블 `id BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY` + 7대 감사 컬럼(`created_at`, `created_by`, `updated_at`, `updated_by`, `is_deleted`, `deleted_at`, `deleted_by`) 보유. FK는 전부 `ON DELETE RESTRICT`.

### 1.1 `accounts` `[MUTABLE]`
| 컬럼 | 물리 타입 | 제약 / 설명 |
| :--- | :--- | :--- |
| `provider` | `auth_provider` ENUM | `EMAIL \| KAKAO \| NAVER \| GOOGLE \| APPLE` |
| `provider_id` | `VARCHAR(191) NOT NULL` | 이메일 로그인 시 소문자 이메일, 소셜 로그인 시 외부 고유 ID |
| `email` | `VARCHAR(191) NULL` | 이메일 주소 (`idx_accounts_email`) |
| `email_verified_at` | `TIMESTAMPTZ(3) NULL` | 이메일 인증 일시 |
| `password_hash` | `TEXT NULL` | `scrypt$<salt>$<hex>` (`00_lib/password.ts`) |
| `failed_login_count` | `INTEGER NOT NULL DEFAULT 0` | 오답 누적 횟수 |
| `locked_until` | `TIMESTAMPTZ(3) NULL` | 잠금 해제 시각 |
- **Partial Unique**: `uq_accounts_provider_active (provider, provider_id) WHERE is_deleted = false`

### 1.2 `users` `[MUTABLE]`
| 컬럼 | 물리 타입 | 제약 / 설명 |
| :--- | :--- | :--- |
| `account_id` | `BIGINT NOT NULL` | FK → `accounts.id` (`RESTRICT`) |
| `nickname` | `VARCHAR(60) NOT NULL` | 보호자 닉네임 |
| `phone`, `region`, `profile_image` | `VARCHAR / TEXT NULL` | 연락처, 지역, 프로필 이미지 URL |
| `status` | `user_status` ENUM | `ACTIVE \| SUSPENDED \| DELETED` (`idx_users_status`) |
| `marketing_opt_in`, `push_opt_in`, `education_push_opt_in` | `BOOLEAN NOT NULL` | 마케팅/전체푸시/교육리마인드 수신 동의 |
| `onboarding_completed_at`, `last_login_at` | `TIMESTAMPTZ(3) NULL` | 온보딩 완료 시각, 최근 로그인 시각 |
- **Partial Unique**: `uq_users_account_active (account_id) WHERE is_deleted = false`

### 1.3 `devices` `[MUTABLE]`
- `user_id` (FK `users.id`), `platform` (`IOS \| ANDROID \| WEB`), `push_token` (`VARCHAR(512)`), `app_version`, `os_version`, `last_seen_at`.
- **Partial Unique**: `uq_devices_user_token_active (user_id, push_token) WHERE is_deleted = false`

### 1.4 `auth_sessions` `[MUTABLE]` — 보호자 SHA-256 단일 세션
- `user_id` (FK `users.id`), `token_hash` (`VARCHAR(64) UNIQUE`), `user_agent`, `ip_address`, `last_seen_at`, `revoked_at`, `revoked_reason` (`DUPLICATE_LOGIN \| LOGOUT \| SECURITY_RESET \| ADMIN_FORCE`).
- 정책 (`00_lib/userSessionConfig.ts` + `.env`): **자동 로그아웃 없음 (`idleMs: null`, `absoluteMs: null`)**, 쿠키 `WAGGLE_APP_SESSION` (`path: "/"`, `maxAge: 365일` 슬라이딩 재발급), **`singleSession: true`**.

### 1.5 `admins` `[MUTABLE]`
- `email` (`VARCHAR(191)`), `password_hash`, `name`, `phone` (SMS 2FA 수신), `role` (`ADMIN \| TRAINER`), `status` (`ACTIVE \| INACTIVE \| LOCKED \| SUSPENDED`), `failed_login_count`, `locked_at`, `last_login_at`.
- **Partial Unique**: `uq_admins_email_active (email) WHERE is_deleted = false`

### 1.6 `admin_sessions` `[MUTABLE]` — 관리자 30분 슬라이딩 단일 세션
- `admin_id` (FK `admins.id`), `token_hash` (`VARCHAR(64) UNIQUE`), `expires_at` (`TIMESTAMPTZ(3)`), `last_seen_at`, `revoked_at`, `revoked_reason`.
- 정책 (`00_lib/adminSessionConfig.ts` + `.env`): 쿠키 `WAGGLE_ADMIN_SESSION` (**`path: "/admin"`** 물리 분리), **30분 슬라이딩 만료**, 단일 세션.

### 1.7 `admin_otp_codes` `[MUTABLE]` — 관리자 2단계 SMS OTP
- `admin_id` (FK `admins.id`), `challenge_token_hash` (`UNIQUE`), `code_hash` (6자리 OTP SHA-256), `dev_plain_code` (`NODE_ENV !== 'production'` Mock 화면 표시용), `expires_at`, `consumed_at`.
- 챌린지 쿠키: `WAGGLE_ADMIN_OTP` (`path: "/admin"`).
