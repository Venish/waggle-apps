## 2. 3단계 레슨 루프 & ACID 보상 규칙

- **순수 계산식 (`packages/types/src/domain/education-math.ts`)**: `computeLessonStates()` (순차 잠금/현재/완료 판정), `calcProgressPercent()`, `calcDogGrade()`.
- **동적 정책 키 (`policy_configs`)**: `watch.complete_percent` (95), `quiz.pass_percent` (80), `point.watch` (30), `point.practice` (20), `point.quiz` (50), `point.bonus.unit` (100), `point.bonus.course` (300), `point.daily_earn_cap` (500).

| 기능 ID | 기능명 | 구현 진입점 | 트랜잭션 / 멱등성 계약 |
| :---: | :--- | :--- | :--- |
| `D04-F01` | 코스 수강 신청 & 프리미엄 잠금 검증 | `enrollCourseAction` | `courses.is_premium=true`인 경우 `course_unlocks` 보유 여부 검증 후 `enrollments` 생성 |
| `D04-F02` | 1단계 영상 시청 완료 | `completeLessonWatchAction` | `watchedPercent >= watch.complete_percent` 판정 ➔ 단일 `db.transaction` 내 `watch_point_awarded=false→true` 전이 + `earnPointsTx` (멱등키 `lesson:{dogId}:{lessonId}:watch`, 일일 상한 체크) |
| `D04-F03` | 2단계 실습 체크리스트 완료 | `completeLessonPracticeAction` | 전체 체크 항목 완료 검증 ➔ `practice_point_awarded=false→true` + `earnPointsTx` (멱등키 `lesson:{dogId}:{lessonId}:practice`) |
| `D04-F04` | 3단계 퀴즈 채점 · 레슨/유닛/코스 완주 · 배지/학년 승급 | `submitLessonQuizAction` | `quiz_attempts` 기록 ➔ 통과(`>= quiz.pass_percent`) 시 `quiz_passed_at` & `completed_at` 확정 ➔ 퀴즈/유닛/코스 보너스 원장 적립 + `dog_badges` 해금 + `dogs.grade` 동기 갱신 |
| `D04-F05` | 관리자 코스 CMS & 빠른 유닛·3단계 레슨 추가 | `adminUpsertCourseAction`, `adminAddUnitAndLessonAction`, `adminSoftDeleteCourseAction` | `enrollments` 존재 코스 삭제 시 `REFERENCE_BLOCKED` Alert 차단 |
