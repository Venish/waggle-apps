## 1. PostgreSQL 18 물리 테이블 명세 (4개)

### 1.1 `point_wallets` `[MUTABLE]`
- `user_id` (FK `users.id`), `balance` (`BIGINT NOT NULL DEFAULT 0`, 음수 불가).
- **Partial Unique**: `uq_point_wallets_user_active (user_id) WHERE is_deleted = false`
- **동시성**: `ensureWalletLocked()`에서 `INSERT ... ON CONFLICT (user_id) WHERE is_deleted = false DO NOTHING` 후 `FOR UPDATE` (전역 잠금 순서 1순위).

### 1.2 `point_ledgers` `[APPEND_ONLY]` — 불변 원장
- `user_id` (FK `users.id`), `dog_id`, `delta` (`BIGINT`, 적립 `+`/차감 `-`), `balance_after` (`BIGINT`), `reason` (`point_reason` ENUM **16종**: `EARN_EDUCATION_*`, `EARN_BONUS_*`, `EARN_LEVEL_TEST`, `EARN_RECHARGE`, **`REVIEW_REWARD`**, `SPEND_SHOP`, `SPEND_INQUIRY`, `SPEND_COURSE_UNLOCK`, `REFUND`, **`RECHARGE_REFUND`**, `EXPIRE`, `ADMIN_GRANT`, `ADMIN_REVOKE`), `idempotency_key` (`VARCHAR(191)`), `ref_type`, `ref_id`, `memo`, `expires_at` (`TIMESTAMPTZ(3)`), `remaining_amount` (`BIGINT`, FIFO 잔여량 전이만 허용), `created_by`, `created_at`.
- **Partial Unique**: `uq_point_ledgers_idempotency (idempotency_key) WHERE idempotency_key IS NOT NULL`

### 1.3 `payment_event_logs` `[APPEND_ONLY]` — 웹훅 멱등 로그
- `provider` (`PORTONE` 등), `event_id` (`VARCHAR(191)`), `recharge_id`, `event_type`, `payload` (`JSONB`), `created_at`.
- **Unique**: `uq_payment_event_provider_id (provider, event_id)`

### 1.4 `point_recharges` `[MUTABLE]` — 충전 주문 · 환불
- `user_id` (FK `users.id`), `channel` (`WEB_PG \| IOS_IAP \| ANDROID_IAP`), `package_code`, `point_amount` (`BIGINT`), `paid_amount` (`BIGINT`), `currency` (`KRW`), `provider`, `payment_id`, `idempotency_key` (`VARCHAR(100)`), `receipt` (`JSONB`), `status` (`PENDING \| PAID \| FAILED \| CANCELLED \| REFUND_REQUESTED \| REFUNDED`), `paid_at`, `refunded_at`, `refund_reason`, `refunded_point_amount` (`BIGINT`), `refunded_cash_amount` (`BIGINT`), `admin_reject_reason`.
- **Partial Unique**:
  - `uq_point_recharges_provider_payment (provider, payment_id) WHERE payment_id IS NOT NULL AND is_deleted = false`
  - `uq_point_recharges_idempotency (idempotency_key) WHERE idempotency_key IS NOT NULL`
