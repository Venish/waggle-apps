## 2. Stage 2 기계 파싱용 3종 MD 표준 규격 (`.scratch/spec_verifier` 대비)

- **`01_table.md`**: 테이블별 `### N. \`table_name\` [MUTABLE | APPEND_ONLY]` 헤더 + 컬럼 표(`컬럼명 | 물리 타입 | NULL | 기본값 | 설명`) + `인덱스 / 유니크` + `외래키 / 삭제 차단 규칙`.
- **`02_feature.md`**: `### D{폴더}-F{순번}: 기능명` 헤더 + 대상 테이블 + `Zod` 입력 + 트랜잭션/멱등성 규칙 + `Repo / Service / Action(또는 API)` 시그니처.
- **`03_screen.md`**: `### SCR-{코드}: 화면명` 헤더 + Route/Role/디자인SSOT + UI 필드 매핑 표(`화면 항목 | table.column | 타입/포맷 | 필수`) + `Step-by-Step User Flow` 3종(기본 · 연계 · 예외/차단).
