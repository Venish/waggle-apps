# 포인트샵 고도화 · 리치 상품 상세 · 구매 확정 후기 시스템 설계

- **작성일**: 2026-11-23
- **범위**: `@repo/db`, `@repo/types`, `@repo/web` (`(mobile)` + `(admin)` + `/api/upload` + `/admin/api/upload` + `/api/uploads/[...path]` + `/api/cron/confirm-orders`)
- **핵심 원칙**: KISS, `web/` ↔ `admin/` 물리 격리, 쿠키 경로(`path: "/admin"`) 유지, GM-011 Strict `.env` & `policy_configs`

## 1. 핵심 아키텍처 & 사전 점검 반영 사항 (7대 리스크 해소)

1. **관리자 쿠키 격리 + 업로드 경로 분리**:
   - `WAGGLE_ADMIN_SESSION` 쿠키는 `path: "/admin"`으로 고정되어 있으므로, 관리자 이미지 업로드는 **`POST /admin/api/upload`**(`app/(admin)/admin/api/upload/route.ts`)로 분리.
   - 사용자 후기/문의 업로드는 **`POST /api/upload`**(사용자 세션 전용).
2. **`.env` 기반 업로드 저장소 & 안전 서빙**:
   - `.env` / `.env.example` / `turbo.json` / `00_lib/env.ts`에 `UPLOAD_DIR`(기본 `./uploads`, 모노레포 루트 기준 해석, 절대경로 지원) 및 `UPLOAD_PUBLIC_BASE_URL`(기본 `/api/uploads`) 등록.
   - **`GET /api/uploads/[...path]`** Route Handler로 서빙 (Path Traversal 차단 + `Cache-Control: public, max-age=31536000, immutable`) → `next start` 운영 빌드 404 및 외부 볼륨 경로 문제 원천 해결.
3. **`sharp` WebP 자동 최적화 + 보안**:
   - `next.config.ts`에 `serverExternalPackages: ["pg", "sharp"]` 추가.
   - 상품(`products`), 상세 에디터(`editor`), 후기(`reviews`) 업로드는 `sharp(buf).rotate().resize({ width: 1200, withoutEnlargement: true }).webp({ quality: 82 })` 강제 재인코딩 → 확장자 스푸핑 차단 + EXIF GPS 제거.
4. **소프트 삭제 복원 정합성**:
   - `product_images` / `products` 소프트 삭제 시 디스크 파일 물리 삭제 금지 (복원 시 이미지 깨짐 방지).
5. **구매 확정(`CONFIRMED`) → 후기 작성 구조 (체리피킹 원천 차단)**:
   - 주문 상태에 `CONFIRMED` (`confirmed_at`) 추가.
   - `DELIVERED` 상태에서는 `[구매 확정]` 또는 `[반품 신청]`(7일 이내)만 가능.
   - `CONFIRMED` 확정 시(사용자 클릭 또는 `/api/cron/confirm-orders` 7일 자동 확정) 반품 불가 확정 + **실물(`PHYSICAL`) 품목에 한해 `[후기 작성]` 버튼 활성화**.
   - 디지털 상품(`PREMIUM_UNLOCK`, `INQUIRY_TICKET`)은 후기 탭·버튼 제외.
6. **후기 포인트 적립 (`policy_configs` 관리자 제어)**:
   - 기본 시드: `shop.review.text_reward_point = 100`, `shop.review.photo_reward_point = 300`, `shop.review.min_length = 20`, `shop.review.max_length = 500`.
   - `product_reviews`에 `order_item_id` Partial UNIQUE(`WHERE is_deleted = false`)로 품목당 1회 작성 보장.
   - 최초 작성 시 단일 `db.transaction`으로 `REVIEW_REWARD` 포인트 1회 지급 (`idempotencyKey = "review-reward:{reviewId}"`).
   - 사용자 **삭제 불가 · 내용 수정만 허용**(수정 시 추가 포인트 변동 없음), 관리자는 **숨김(블라인드) 토글 & 공식 답글** 지원.
7. **리치 HTML 새니타이징 & UI 디테일**:
   - 관리자 상품 상세는 React 19 호환 **Tiptap** 에디터 + 저장 시 `sanitize-html` 서버 새니타이징.
   - `web.css` / `admin.css` 각각에 경량 `.waggle-prose` / `.admin-prose` 타이포 스타일 추가.

## 2. 화면별 UX 명세

### 2.1 모바일 포인트샵 (`(mobile)`)
- **리스트 (`/app/shop`)**:
  - 2열 쇼핑몰 이미지 카드 (`aspect-square`, 품절 오버레이, 타입 배지, 상품명 2줄, 포인트 가격, 실물 상품 별점★·후기수).
  - 이미지 미등록 상품: **`bg-brand`** 배경 + 중앙 **`<WaggleMark />`** (`text-surface/90`, 테마 컬러 자동 연동).
  - 정렬 필터 (`기본순` / `낮은 포인트` / `높은 포인트` / `후기 많은순`) + 카테고리 탭.
- **상품 상세 (`/app/shop/products/[id]`)**:
  - 상단 가로 100% 풀블리드 **Peek Swiper** (`2장 이상` 시 우측에 다음 이미지 일부 노출 + 스냅 스크롤 + `1 / N` 인디케이터 + 탭 시 라이트박스 확대; `1장`은 100% 풀블리드; `0장`은 `bg-brand` + `<WaggleMark />`).
  - 상품 기본 정보(실물 상품은 `★ 평점 (N) >` 클릭 시 후기 탭 점프) + `PointBalanceRechargeStrip` + 기존 옵션 + 하단 `ProductBuySheetBar`.
  - 하단 **Sticky 탭 (`상품 상세` | `후기 N`)**: `SubPageHeader` 바로 아래 밀착, 탭 전환 시 컨테이너 상단 스크롤 보정.
  - **`후기` 탭**: 상단 평점 요약(평균 + 5~1점 가로 분포 막대 + 포토 스트립) → 구매 확정 미작성자 전용 `후기 작성` 버튼 → 포토만 보기/정렬 → **기본 3줄 요약 + 실제 overflow 시 클릭/`더보기·접기` 인라인 펼침** + 라이트박스 + 관리자 답글 + 본인 후기 `수정` 버튼.
- **주문내역 (`/app/shop/orders`)**:
  - `DELIVERED` 실물 주문: `[구매 확정]` + `[반품 신청]`.
  - `CONFIRMED` 실물 주문: 품목별 `[후기 작성 (+최대 N P)]` / 작성 완료 시 `[후기 수정]`.

### 2.2 관리자 콘솔 (`(admin)`)
- **상품 등록/수정 (`/admin/products/new`, `/admin/products/[id]`)**:
  - 멀티 이미지 업로더(`/admin/api/upload?category=products` — 추가·대표 지정·순서 변경·삭제) + 기본 정보/요약 + **Tiptap 리치 에디터**(`/admin/api/upload?category=editor`) + `/admin/products/[id]` 하단 해당 상품 후기 관리 패널.
- **상품 목록 (`/admin/products`)**: 썸네일 미리보기 + 평점/후기수 표시.
- **후기 통합 관리 (`/admin/reviews`, `A-15`)**:
  - 상단 후기 포인트/글자수 정책 빠른 수정 바 + 상태 필터(전체/미답변/포토/숨김) + 후기 목록·포토 확대·숨김 토글·관리자 공식 답글 작성.
- **주문 관리 (`/admin/orders`)**: `CONFIRMED`(구매확정) 상태 배지·필터 반영.
