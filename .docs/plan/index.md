## 신규 플랜 문서 작성 규칙
1. **파일 생성 위치**: 신규 기능 설계나 `/plan` 수행 시 프로젝트 루트나 `.docs/architecture/`에 생성하지 않고 반드시 **`.docs/plan/YYYY-MM-DD_도메인_제목.md`** 형식으로 생성합니다.
2. **인덱스 동기화**: 새 설계서 작성 시 본 파일(`.docs/plan/index.md`)의 표 최상단에 링크와 1줄 요약을 등록합니다.
3. **Stage 1 상세 설계 확장 (선택적 표준)**: 대규모 도메인 재기획·DB/화면 1:1 정합성 검증이 필요할 경우 `.docs/plan/details/` 하위에 `00_0_상세설계_태스크보드.md`, `00_0_GRILL_ME_결정대장.md` 및 도메인별 `01_table.md · 02_feature.md · 03_screen.md` 구조를 확장할 수 있습니다.
