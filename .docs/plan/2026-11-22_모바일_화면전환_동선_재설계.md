## 1. 해결할 문제와 설계 목표

1. **2중 헤더 & 불필요한 하단 탭 바 제거**: 기존에는 서브 페이지(`/app/shop/products/[id]` 등)에서도 메인 상단 `Waggle` 헤더(`MobileTopHeader`)와 하단 5탭 바(`BottomNavBar`)가 계속 노출되어 `← 상품 상세`가 아래로 밀리고 본문 영역이 좁아짐.
2. **배경이 보이는 슬라이드업 시트 UX**: `+ 기록 작성`, `교환하기`, `포인트 충전`, `질문 작성`, `반려견 추가` 같은 단기 입력·선택 액션은 뒤 화면을 어둡게 깔아 맥락을 유지한 채 `GlobalOverlayProvider (z-40)` 시트로 올려 네이티브 앱 감각 구현.
3. **레이어·뒤로가기·라우팅 꼬임 원천 차단**: 단일 LIFO 레이어 매니저와 4단 Z-Index 계층(`Alert z-60 → CenterModal z-50 → Sheet z-40 → Page z-10~30`)으로 중첩 닫힘 및 `router.push` 충돌 제거.
4. **5대 대표 탭 블록별 순차 상승(Stagger) 모션**: 순수 CSS Zero-JS(`.waggle-stagger`)로 5대 탭 진입 시 직계 블록이 경쾌하게 아래→위로 올라오도록 개선 (`backwards` 전용으로 `fixed`/`sticky` 부작용 차단).

## 3. 4단 비충돌 레이어 스택 & 치명 버그 5종 방어선

| Z-Index | 레이어 | 컴포넌트 | 닫기 우선순위 & 규칙 |
| :---: | :--- | :--- | :--- |
| **`z-60`** | 최상위 알림/확인 | `WebGlobalAlert` | `closeOnOverlayClick={false}`, `closeOnEscape={false}`, 물리 뒤로가기 시 Alert만 닫음 |
| **`z-50`** | 중앙 피커 모달 | `AppCenterModal` (`AppDatePicker`·`AppTimePicker`·`AppSelectPicker`) | 백드롭·ESC·물리 뒤로가기 시 피커만 닫고 부모 시트 유지 |
| **`z-40`** | 배경 유지 슬라이드업 시트 | `GlobalOverlayProvider` | **Max Depth = 1** (중복 시트 적재 금지, 교체만 허용), `pathname` 변경 시 자동 해제 |
| **`z-10~30`** | 페이지 본문 & 메뉴 | `SubPageHeader (z-20)` / `MobileTopHeader (z-20)` / `BottomNavBar (z-30)` | `ROOT_TAB` 5곳에만 상·하단 메뉴 표시 |

### 선반영 방어선 5가지
1. **단일 LIFO 히스토리/ESC/스크롤락 매니저 (`useModalHistory.ts`)**: 개별 `popstate` 리스너 충돌 제거, `ignorePopCount`로 피커 `[확인]` 시 부모 시트 동시 닫힘 차단, `body.style.overflow` 레퍼런스 카운트 단일 관리.
2. **라우트 이동 전용 해제 (`dismissForNavigation`)**: 시트 안에서 `router.push()` 실행 시 `history.back()` 호출 생략 + `usePathname()` 변경 감지로 잔여 시트 즉시 정리.
3. **`WebGlobalAlert` z-index 상향**: `z-50` → `z-60` (시트·피커 위 최상단 보장).
4. **시트 Max Depth = 1 강제 (`useModalStore.ts`)**: 2중 시트 적재 차단.
5. **`backwards` 전용 CSS 모션 (`styles/web.css`)**: 종료 후 `transform` 잔존으로 인한 `sticky`/`fixed` 깨짐 차단 + `prefers-reduced-motion` 존중.

## 5. 5대 대표 탭 블록별 순차 상승 모션 (`.waggle-stagger`)

- **적용 대상**: `/app`, `/app/record`, `/app/daily`, `/app/shop`, `/app/my`
- **감각 파라미터 (`styles/web.css`)**:
  - 이동 거리: `0.75rem` (약 12px) + `opacity: 0 → 1`
  - 지속 시간 및 이징: `300ms`, `cubic-bezier(0.22, 1, 0.36, 1)`
  - 블록 간격 & 상한: `50ms` 간격, 6번째 이후 블록은 `240ms` 상한 고정 (총 ~0.5초 이내 완결)
  - `animation-fill-mode: backwards` 전용 + `/app/daily` 플로팅 FAB는 스태거 래퍼 바깥 배치
