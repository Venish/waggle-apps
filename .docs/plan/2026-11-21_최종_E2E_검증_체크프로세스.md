## 1. 도메인별 Step-by-Step 검증 체크리스트

### [STEP 1] `(www)` 소개 랜딩 & 3도메인 격리 (`SCR-W01`)
- [ ] `http://localhost:3000/` 접속 → Clean Neo-Pop 5색 파스텔 카드(전부 딥 블랙 `text-ink`) 및 상단 **PostgreSQL 18 연결 배지** 정상 표시
- [ ] `[앱 시작하기]` 클릭 → `/app` (또는 비로그인 시 온보딩/로그인) 진입 확인
- [ ] `[Admin 콘솔]` 클릭 → `/admin/login` 진입 시 Atlas Precision Studio 다크 테마(`1rem = 16px`)로 완전 독립 렌더링 확인

### [STEP 2] 보호자 인증 · 중복 로그인 금지 · 영구 세션 (`SCR-U01 ~ U04`)
- [ ] `/app/onboarding/intro` → 슬라이드 확인 후 `/app/onboarding/signup`에서 신규 이메일 가입 → 자동 로그인 + `/app/onboarding/profile` 이동
- [ ] `/app/onboarding/login`에서 `user@waggle.kr` / `Waggle1234!` 로그인 → `WAGGLE_APP_SESSION` 쿠키 발급 확인
- [ ] **[중복 로그인 차단 테스트]**: 시크릿 창(또는 다른 브라우저)에서 `user@waggle.kr`로 재로그인 → 기존 브라우저에서 `/app` 새로고침 시 `/api/auth/session-expired?reason=duplicate` 경유 후 로그인 화면에서 **`WebGlobalAlert` 중복 로그인 안내** 표시 확인
- [ ] 카카오 / Apple Mock 소셜 로그인 버튼 클릭 → `/api/auth/callback/kakao` 정상 세션 발급 확인

### [STEP 3] 온보딩 설문 · 레벨테스트 · 태그 매칭 · 데일리 목표 (`SCR-U05 ~ U10`)
