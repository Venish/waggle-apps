## 1. 핵심 설계 원칙 — 2축 직교 모델 (`Color × Mode`)

```text
<html data-web-theme="orange | green | sky | coral" data-web-mode="light | dark">
```

- **축 1 — 브랜드 컬러 (`data-web-theme`)**: `orange`(기본, `#EF8125`) · `green` · `sky` · `coral`
- **축 2 — 화면 모드 (`data-web-mode`)**: `system`(OS 추종) · `light`(기본) · `dark` — 실제 DOM 속성에는 해석된 `"light"` 또는 `"dark"`만 기록해 CSS 셀렉터를 단순화한다.
- **FOUC 0ms 보장**: `(mobile)/layout.tsx` · `(www)/layout.tsx` `<head>`의 `WEB_THEME_BOOTSTRAP_SCRIPT`에서 First Paint 전에 두 속성을 동시에 세팅하고 `color-scheme: dark`도 연동한다.
- **`(admin)` 100% 물리 격리**: `(admin)`은 `data-admin-theme` + `styles/admin.css`만 소비하므로 사용자 다크 모드와 상호 간섭 0%.

## 2. OKLCH 다크 모드 팔레트 및 핵심 결함 사전 차단 (Pre-Flight Audit)

### 2.1 베이스 서피스 & 타이포 (OKLCH Cool-Neutral Dark, 순수 `#000` 지양)

| `--color-surface` | `oklch(1 0 0)` | `oklch(0.185 0.006 255)` | 카드·시트·모달·헤더 (`#1B1E23`) |
| `--color-surface-subtle` | `oklch(0.978 0.001 250)` | `oklch(0.235 0.007 255)` | 보조 버튼·인풋 트랙·구분 바 (`#262A31`) |

### 2.2 다크 모드 × 4종 브랜드 컬러 자동 역보정 (`[data-web-mode="dark"][data-web-theme="..."]`)
다크 배경(`L=0.145~0.185`) 위에서는 Light용 `brand-strong`(`L=0.55`)이 어둡고, `brand-soft`(`L=0.96`)가 눈부시다. 따라서 다크 모드에서는 아래 3가지를 역보정한다.
- **`--color-brand-strong`**: `L=0.77~0.80` 밝은 틴트로 승격 → 어두운 카드 위 텍스트 명암비 **AA+ (7:1+)** 확보.
- **`--color-brand-soft`**: `L=0.25, C=0.055` 딥 틴트로 전환 → 배지·아코디언·선택 카드 배경 눈부심 차단.
- **`--color-brand-stamp`** (캘린더 도장) · **`--waggle-record-from/mid`** (하단 발자국 그라데이션): 저명도 투명 틴트로 전환해 위 흰 숫자와 조화 유지.

### 2.3 실코드 감사로 도출한 5대 깨짐 방지 포인트
1. **`bg-brand text-surface` → `bg-brand text-on-brand` 분리**:
   - 대상: `buttonStyles.ts` (`primary`, `dangerSolid`), `AppBadge.tsx` (`brandSolid`), `AppCheckControls.tsx`, `DailyCalendarClient.tsx`, `DogAvatar` 등.
   - 이유: 다크 모드에서 `--color-surface`가 `#1B1E23`으로 어두워지면 주황/빨강 버튼 글자가 어둡게 죽는 결함을 원천 차단.
2. **`.waggle-liquid-glass` 다크 글래스 분기 (`web.css`)**:
   - 다크 모드에서 상단 반사 림을 `oklch(1 0 0 / 0.14)`로 낮추고 `color-mix(in oklab, var(--color-surface) 74%, transparent)` + 깊은 그림자 적용.
3. **`.waggle-pass-1~5` / `.waggle-pass-locked` (스쿨 패스 카드) 다크 틴트 분기 (`web.css`)**:
   - 다크 모드 전용 딥 파스텔 스팟 그라데이션(`L=0.22~0.34`)으로 전환해 흰 카드 눈부심 방지.
4. **하드코딩 라이트 틴트 10곳 정리 (`TicketCard`, `EducationHomeClient`, `RecordHubClient`, `DailyStickerIcon`)**:
   - `bg-rose-50 text-rose-600` → `bg-destructive/12 text-destructive`
   - `bg-sky-50/85 text-sky-700` → `bg-sky-500/12 text-sky-600 dark:text-sky-400` (또는 CSS 변수/알파 틴트)
   - `RecordHubClient` 5학년 `accentText` / 배지 `auraBg`(`bg-emerald-50` 등) → 라이트/다크 공용 알파 틴트(`bg-emerald-500/12` 등)로 전환.
   - `(mobile)/layout.tsx` 데스크톱 바깥 배경 `sm:bg-ink/[0.06]` → 다크 시 `canvas`보다 살짝 깊은 톤 유지.
5. **Apple 소셜 버튼 & `meta theme-color`**:
   - Apple 원형 버튼(`bg-ink text-surface`)은 다크 모드 시 자동으로 흰 원 + 검정 사과(Apple HIG 다크 공식 규격)로 반전.
   - 테마/모드 변경 시 `<meta name="theme-color">` 동적 갱신으로 모바일 브라우저 상단 주소창 색상까지 일체화.
