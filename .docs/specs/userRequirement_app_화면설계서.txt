9️⃣ UX 흐름 연결성 설계 (핵심)
모든 기능은 수첩으로 귀결
	• 산책 종료 → 자동 수첩 기록
	• 교육 완료 → 수첩 표시
	• 미션 달성 → 수첩 아이콘 표시
	• 의료 기록 → 수첩 점 표시
👉 수첩 = 반려견의 라이프 타임라인
