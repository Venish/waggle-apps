## 1. 스타일링 시스템 결정

### 1.1 선택: NativeWind v4 + react-native-reusables

ShadCN/UI는 Radix UI(브라우저 DOM) + Tailwind CSS(브라우저 CSS)에 종속되므로 React Native에서 직접 사용 불가.
대신 아래 조합으로 ShadCN과 동일한 철학(copy-paste 컴포넌트, semantic token, variant 패턴)을 구현한다.

| 레이어 | 라이브러리 | 역할 |
|---|---|---|
| 스타일 엔진 | **NativeWind v4** | Tailwind CSS 문법 → RN StyleSheet 변환 |
| 컴포넌트 기반 | **react-native-reusables** | ShadCN 포팅 RN 컴포넌트 (Button, Card 등) |
| 애니메이션 | **Reanimated 3** | 제스처, 전환, 팝업 |
| 그래픽 | **React Native Skia** | 승급 애니메이션, confetti |
| Lottie | **lottie-react-native** | 불꽃/뱃지 효과 |

### 1.2 설치 명령

```bash

# Reanimated + Skia
```

```typescript
// src/components/ui/button.tsx
import React from 'react';
import { Pressable, Text, ActivityIndicator, PressableProps } from 'react-native';
import { cva, type VariantProps } from 'class-variance-authority';
import { cn } from '@/lib/utils/cn';

const buttonVariants = cva(
  'flex-row items-center justify-center rounded-xl active:opacity-80',
  {
    variants: {
      variant: {
        default:     'bg-primary',
        secondary:   'bg-secondary',
        destructive: 'bg-destructive',
        ghost:       'bg-transparent',
        outline:     'bg-transparent border border-border',
        walk:        'bg-walk',
        education:   'bg-education',
        mission:     'bg-mission',
        point:       'bg-point',
      },
      size: {
        sm:   'h-9 px-4',
        md:   'h-12 px-6',
        lg:   'h-14 px-8',
        icon: 'h-10 w-10',
      },
    },
    defaultVariants: { variant: 'default', size: 'md' },
  }
);

const textVariants = cva('font-semibold', {
  variants: {
    variant: {
      default:     'text-primary-foreground',
      secondary:   'text-secondary-foreground',
      destructive: 'text-destructive-foreground',
      ghost:       'text-foreground',
      outline:     'text-foreground',
      walk:        'text-white',
      education:   'text-white',
      mission:     'text-white',
      point:       'text-white',
    },
    size: {
      sm: 'text-sm',
      md: 'text-base',
      lg: 'text-lg',
      icon:'text-base',
    },
  },
  defaultVariants: { variant: 'default', size: 'md' },
});

interface ButtonProps extends PressableProps, VariantProps<typeof buttonVariants> {
  children: React.ReactNode;
  loading?: boolean;
  leftIcon?: React.ReactNode;
  rightIcon?: React.ReactNode;
  className?: string;
  textClassName?: string;
}

export function Button({
  children, variant, size, loading, leftIcon, rightIcon,
  className, textClassName, disabled, ...props
}: ButtonProps) {
  const isDisabled = disabled || loading;

  return (
    <Pressable
      className={cn(buttonVariants({ variant, size }), isDisabled && 'opacity-50', className)}
      disabled={isDisabled}
      {...props}
    >
      {loading ? (
        <ActivityIndicator color="white" size="small" />
      ) : (
        <>
          {leftIcon}
          <Text className={cn(textVariants({ variant, size }), textClassName)}>
            {children}
          </Text>
          {rightIcon}
        </>
      )}
    </Pressable>
  );
}
```

### 3.3 `Input` 컴포넌트

```typescript
// src/components/ui/input.tsx
import React, { forwardRef, useState } from 'react';
import { TextInput, TextInputProps, View, Text, Pressable } from 'react-native';
import { cn } from '@/lib/utils/cn';

interface InputProps extends TextInputProps {
  label?: string;
  error?: string;
  hint?: string;
  leftIcon?: React.ReactNode;
  rightIcon?: React.ReactNode;
  containerClassName?: string;
}

export const Input = forwardRef<TextInput, InputProps>(({
  label, error, hint, leftIcon, rightIcon,
  containerClassName, className, ...props
}, ref) => {
  const [focused, setFocused] = useState(false);
  const hasError = !!error;

  return (
    <View className={cn('gap-1', containerClassName)}>
      {label && (
        <Text className="text-sm font-medium text-foreground">{label}</Text>
      )}
      <View className={cn(
        'flex-row items-center h-12 px-4 rounded-xl border bg-background',
        focused ? 'border-ring' : 'border-border',
        hasError && 'border-destructive',
      )}>
        {leftIcon && <View className="mr-2">{leftIcon}</View>}
        <TextInput
          ref={ref}
          className={cn('flex-1 text-base text-foreground', className)}
          placeholderTextColor="#94A3B8"
          onFocus={() => setFocused(true)}
          onBlur={() => setFocused(false)}
          {...props}
        />
        {rightIcon && <View className="ml-2">{rightIcon}</View>}
      </View>
      {(error || hint) && (
        <Text className={cn('text-xs', hasError ? 'text-destructive' : 'text-muted-foreground')}>
          {error ?? hint}
        </Text>
      )}
    </View>
  );
});
```

```typescript
import { View, ViewProps } from 'react-native';
import { cn } from '@/lib/utils/cn';

interface CardProps extends ViewProps {
  variant?: 'default' | 'elevated' | 'outlined';
  className?: string;
}

export function Card({ variant = 'default', className, children, ...props }: CardProps) {
  return (
    <View
      className={cn(
        'rounded-2xl p-4 bg-card',
        variant === 'elevated' && 'shadow-md',
        variant === 'outlined' && 'border border-border',
        className,
      )}
      {...props}
    >
      {children}
    </View>
  );
}

export function CardHeader({ className, children, ...props }: ViewProps & { className?: string }) {
  return <View className={cn('mb-3', className)} {...props}>{children}</View>;
}

export function CardContent({ className, children, ...props }: ViewProps & { className?: string }) {
  return <View className={cn('', className)} {...props}>{children}</View>;
}

export function CardFooter({ className, children, ...props }: ViewProps & { className?: string }) {
  return <View className={cn('mt-3', className)} {...props}>{children}</View>;
}
```

### 3.5 `Progress` 컴포넌트

```typescript
// src/components/ui/progress.tsx
import React, { useEffect } from 'react';
import { View, Text } from 'react-native';
import Animated, { useSharedValue, withTiming, useAnimatedStyle, Easing } from 'react-native-reanimated';
import { cn } from '@/lib/utils/cn';

interface ProgressProps {
  value: number;         // 0–100
  max?: number;
  label?: string;
  showValue?: boolean;
  variant?: 'default' | 'walk' | 'education' | 'mission';
  className?: string;
}

const trackColors: Record<string, string> = {
  default:   'bg-primary',
  walk:      'bg-walk',
  education: 'bg-education',
  mission:   'bg-mission',
};

export function Progress({ value, max = 100, label, showValue, variant = 'default', className }: ProgressProps) {
  const pct = Math.min(100, Math.max(0, (value / max) * 100));
  const width = useSharedValue(0);

  useEffect(() => {
    width.value = withTiming(pct, { duration: 600, easing: Easing.out(Easing.cubic) });
  }, [pct]);

  const barStyle = useAnimatedStyle(() => ({ width: `${width.value}%` }));

  return (
    <View className={cn('gap-1', className)}>
      {(label || showValue) && (
        <View className="flex-row justify-between">
          {label && <Text className="text-xs text-muted-foreground">{label}</Text>}
          {showValue && <Text className="text-xs font-medium text-foreground">{Math.round(pct)}%</Text>}
        </View>
      )}
      <View className="h-2 bg-muted rounded-full overflow-hidden">
        <Animated.View className={cn('h-full rounded-full', trackColors[variant])} style={barStyle} />
      </View>
    </View>
  );
}
```

### 3.9 `PointPopup` 애니메이션 컴포넌트

```typescript
// src/components/domain/animations/point-popup.tsx
import React, { useEffect } from 'react';
import { View, Text } from 'react-native';
import Animated, {
  useSharedValue, useAnimatedStyle, withSequence,
  withTiming, withSpring, runOnJS, Easing,
} from 'react-native-reanimated';

interface PointPopupProps {
  points: number;
  visible: boolean;
  onHide?: () => void;
  label?: string;   // 기본: '+{points}P'
}

export function PointPopup({ points, visible, onHide, label }: PointPopupProps) {
  const opacity = useSharedValue(0);
  const translateY = useSharedValue(0);
  const scale = useSharedValue(0.8);

  useEffect(() => {
    if (!visible) return;

    opacity.value = 0;
    translateY.value = 0;
    scale.value = 0.8;

    opacity.value = withSequence(
      withTiming(1, { duration: 200 }),
      withTiming(1, { duration: 1000 }),

    scale.value = withSpring(1, { damping: 10, stiffness: 200 });

    const timer = setTimeout(() => { onHide?.(); }, 1700);
    return () => clearTimeout(timer);
  }, [visible]);

  const style = useAnimatedStyle(() => ({
    opacity: opacity.value,
    transform: [{ translateY: translateY.value }, { scale: scale.value }],
  }));

  if (!visible) return null;

  return (
    <Animated.View
      pointerEvents="none"
      style={[style, { position: 'absolute', alignSelf: 'center', zIndex: 9999 }]}
    >
      <View className="bg-point px-4 py-2 rounded-full shadow-lg">
```

```typescript
export const walkKeys = {

    queryKey: walkKeys.list(),
    queryFn: () => walkApi.getList(),

export function useCompleteWalk() {
  const queryClient = useQueryClient();
  const { optimisticAdd, revertOptimistic } = usePointStore();

  return useMutation({
    mutationFn: (sessionId: string) => walkApi.complete(sessionId),

    onMutate: async (sessionId) => {
      // 낙관적 포인트 표시 (서버 응답 전)
      const estimatedPoints = 10; // 실제 계산은 네이티브에서 옴
      optimisticAdd(estimatedPoints);
      return { estimatedPoints };
    },

    onSuccess: (data, _, ctx) => {
      // 실제 포인트로 보정
      revertOptimistic(ctx!.estimatedPoints);
      optimisticAdd(data.pointsEarned);
      queryClient.invalidateQueries({ queryKey: walkKeys.list() });
    },

    onError: (_, __, ctx) => {
      revertOptimistic(ctx!.estimatedPoints);
    },
```

### 7.1 Axios 인스턴스 + 토큰 갱신

```typescript
// src/lib/api/axios-instance.ts
import axios from 'axios';
import { useAuthStore } from '@/lib/store/auth-store';

export const api = axios.create({
  baseURL: process.env.MAPI_BASE_URL ?? 'https://api.waggle.app',
  timeout: 10_000,
  headers: { 'Content-Type': 'application/json' },
});

// Request 인터셉터 — AccessToken 주입
api.interceptors.request.use((config) => {
  const token = useAuthStore.getState().accessToken;
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// Response 인터셉터 — 401 시 토큰 갱신
let isRefreshing = false;
let refreshQueue: Array<(token: string) => void> = [];

api.interceptors.response.use(
  (res) => res,
  async (error) => {
    const original = error.config;
    if (error.response?.status !== 401 || original._retry) throw error;

    original._retry = true;

    if (isRefreshing) {
      return new Promise((resolve) => {
        refreshQueue.push((token) => {
          original.headers.Authorization = `Bearer ${token}`;
          resolve(api(original));
        });
      });
    }

    isRefreshing = true;
    try {
      const refreshToken = useAuthStore.getState().refreshToken;
      const { data } = await axios.post(`${api.defaults.baseURL}/auth/refresh`, { refreshToken });
      useAuthStore.getState().setAuth(
        useAuthStore.getState().user!,
        data.data.accessToken,
        data.data.refreshToken,
      );
      refreshQueue.forEach((cb) => cb(data.data.accessToken));
      refreshQueue = [];
      original.headers.Authorization = `Bearer ${data.data.accessToken}`;
      return api(original);
    } catch {
      useAuthStore.getState().logout();
      throw error;
    } finally {
      isRefreshing = false;
    }
  },
);
```

## 8. 개발 규칙 요약 (AI 코딩 지침)

1. **스타일**: NativeWind `className` 사용. `StyleSheet.create`는 성능 임계 영역(FlatList rowItem, Map overlay)에만 허용.
2. **색상**: 하드코딩(`#F97316`) 금지. 반드시 토큰명(`text-point`, `bg-walk`) 사용.
3. **컴포넌트**: `src/components/ui/`의 Primitive를 조합하여 도메인 컴포넌트 구현. Primitive를 직접 수정하지 말고 className으로 확장.
4. **서버 상태**: TanStack Query 사용. `useEffect` 안에서 `fetch` 직접 호출 금지.
5. **로컬 영구 저장**: MMKV만 사용. AsyncStorage 사용 금지.
6. **애니메이션**: Reanimated 3의 worklet 함수 안에서는 JS 스레드 접근 금지. `runOnJS()` 로 브릿지.
7. **네이티브 WalkMap**: `<NativeWalkMapView />` 컴포넌트는 `src/features/walk/` 에서만 사용. 다른 기능 탭에서 import 금지.
8. **타입**: `any` 사용 금지. API 응답은 반드시 Zod 스키마로 parse.
9. **폼**: React Hook Form + Zod. `useState`로 폼 필드 직접 관리 금지.
10. **에러 바운더리**: 각 Stack의 최상위 Screen에 `ErrorBoundary` 래핑 필수.
