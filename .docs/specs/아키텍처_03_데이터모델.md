## 1. 설계 원칙

1. **이중 PostgreSQL 스키마 (`public` / `admin`)** — 앱 도메인 테이블은 `public` 스키마, 관리자 전용 테이블(Admin, AuditLog, Banner, 정산, 정책)은 `admin` 스키마로 격리. DB 역할(Role)을 분리해 MAPI 서비스 계정은 `public`만, AAPI 서비스 계정은 `public` + `admin`에 접근한다. 백업 스키마(`public_backup`/`admin_backup`)에는 **어떤 서비스 계정에도 권한을 부여하지 않는다**(D24).
2. **포인트는 원장(ledger) 구조** — 잔액 테이블과 원장 테이블을 분리. 잔액은 집계 캐시, 진실 공급원은 원장. 충전분/적립분을 원장에서 구분 관리(정산·환불·IAP 대응).
3. **soft delete** — 사용자 데이터(회원/반려견/주문)는 `deletedAt` 사용. 감사/복구/통계 보존. (§7)
4. **UUID v7 기본키** — 시간 정렬 가능한 UUID. bigint 사용 금지. 외부 노출 ID 분리(필요 시 `publicId`).
5. **타임존** — 서버/DB는 UTC. 표시 시 KST 변환. `timestamptz` 사용.
6. **참조 무결성** — FK + ON DELETE 정책 명시. 포인트 원장·정산은 RESTRICT 성격(원장 자체는 append-only), 로그성은 SET NULL.
7. **진도의 주체는 Dog** — 수강(`Enrollment`)·레슨 진도(`LessonProgress`)·퀴즈 응시·설문 응답·배지는 모두 User가 아닌 **Dog 기준**. 한 계정 다견(多犬) 지원.
8. **정책값 하드코딩 금지 (D16)** — 포인트 단가, 완주 보너스, 충전 패키지 가격, 문의권 가격, 정산 비율, 퀴즈 통과 기준 등은 모두 `admin.PolicyConfig`에서 관리. 지급/차감 시점의 값은 트랜잭션 레코드에 스냅샷 저장.
9. **공간 데이터 제거** — 산책 GPS 트래킹 폐기로 PostGIS 의존이 사라진다. 위치기반 커뮤니티(2차)는 **네이버맵 JS API 기반 클라이언트 처리**라 서버 공간 데이터가 불필요하므로, PostGIS 확장 자체를 제거할 수 있다. (§8)
10. **개인정보 최소화** — 주소는 주문 건별 스냅샷으로만 보관, 기본 배송지는 암호화 컬럼(pgcrypto).

## 2. 스키마 전략 (D24)

```
PostgreSQL (waggle_dev / waggle_prod)
├── public          ← 앱 도메인 전체 (개편하여 계속 사용)
├── admin           ← 관리자 전용 (개편하여 계속 사용)
├── public_backup   ← 피벗 직전 public 스냅샷 (동결·읽기전용, 서비스 계정 권한 없음)
└── admin_backup    ← 피벗 직전 admin 스냅샷 (동결·읽기전용, 서비스 계정 권한 없음)
```

- 전환 시점에 `pg_dump` 파일 백업 + 스키마 단위 스냅샷으로 `public_backup`/`admin_backup` 생성(데이터 포함).
- 백업 스키마는 **동결**: 이후 어떤 마이그레이션도 적용하지 않으며, `waggle_mapi_user`/`waggle_aapi_user`에 USAGE 권한을 부여하지 않는다. 데이터 참조가 필요하면 `prisma_migrator` 또는 DBA 계정으로만 조회.
- `public`/`admin`은 기존 2스키마 체계를 유지한 채 내용만 개편: 코어 유지(User·Dog·Point·Shop·알림·일상기록) + 교육 도메인 신규, Walk 등 폐기 테이블 drop. 상세 절차는 §8.

## 3. 도메인 개괄

```
Account — User — Dog ─┬─ Enrollment (코스 수강, 동시 수강 허용)
        │             │    └─ LessonProgress (레슨 진도: 시청/실습/퀴즈 + 포인트지급 플래그)
        │             ├─ SurveyResponse (온보딩 설문 응답)
        │             ├─ QuizAttempt / LevelTestAttempt
        │             ├─ DogBadge (배지)
        │             ├─ DailyEntry (일상기록 — 포인트 미연동)
        │             └─ VaccinationRecord (의료 기록)
        │
        ├─ PointWallet / PointLedger (원장, expiresAt+remaining로 FIFO 소멸)
        ├─ PointRecharge (PG/IAP 충전)
        ├─ Inquiry (훈련사 비동기 영상 Q&A, 48h SLA)
        ├─ DailyGoal (데일리 목표 + 리마인드)
        ├─ CourseUnlock (프리미엄 콘텐츠 잠금해제)
        └─ Order (포인트샵 주문)

교육:     Course → Unit → Lesson → LessonStep(VIDEO/PRACTICE/QUIZ)
                                     ├─ PracticeChecklist (자가체크 항목)
                                     └─ Quiz → QuizQuestion (4지선다)
매칭:     SurveyQuestion → SurveyAnswer —(AnswerTag)→ Tag ←(CourseTag)— Course
훈련사:   Trainer —(TrainerTag)→ Tag,  Trainer ← Inquiry
Shop:     ProductCategory → Product(실물/문의권/프리미엄) → Order → OrderItem → Shipment
Admin:    Admin(+TRAINER 롤), AuditLog, Banner, TrainerSettlement, PolicyConfig(+History)
```

## 5. Prisma 스키마

> 실제 구현 시 `packages/prisma/prisma/schema.prisma`에 배치. 여기서는 설계 가독성을 위해 섹션별로 나눈다. 모든 모델에 `@@map` + `@@schema`를 명시한다(현행 컨벤션).

### 5.0 Prisma 공통 설정

```prisma
generator client {
  provider        = "prisma-client-js"
  previewFeatures = ["multiSchema"]
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
  schemas  = ["public", "admin"]
}
```

- `public` 스키마: 앱 도메인 전체 (Core/Auth, Dog, 일상기록, Education, Survey/Matching, Trainer/Inquiry, Point, Shop, Notification)
- `admin` 스키마: 관리자 전용 (Admin, AuditLog, Banner, TrainerSettlement, PolicyConfig 및 관련 enum)
- `public_backup`/`admin_backup`은 Prisma 관리 대상이 **아니다** (datasource `schemas`에 포함하지 않음)

### 5.1 Core / Auth (유지)

```prisma
// 소셜 통합 계정 단위
model Account {
  id            String       @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  provider      AuthProvider
  providerId    String       // 소셜 userId 또는 email (이메일 가입 시 email)
  email         String?
  emailVerified DateTime?
  passwordHash  String?      // 이메일 가입 시만 (Argon2id)
  user          User?
  createdAt     DateTime     @default(now())
  updatedAt     DateTime     @updatedAt

  @@unique([provider, providerId])
  @@index([email])
  @@map("Account")
  @@schema("public")
}

enum AuthProvider {
  EMAIL
  KAKAO
  NAVER
  GOOGLE
  APPLE

  @@schema("public")
}

model User {
  id                 String         @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  accountId          String         @unique @db.Uuid
  account            Account        @relation(fields: [accountId], references: [id], onDelete: Cascade)
  nickname           String
  phone              String?
  region             String?
  profileImage       String?
  status             UserStatus     @default(ACTIVE)
  marketingOptIn     Boolean        @default(false)
  pushOptIn          Boolean        @default(true)
  educationPushOptIn Boolean        @default(true)  // 교육 리마인드 개별 토글 (walkPushOptIn은 제거)
  lastLoginAt        DateTime?
  deletedAt          DateTime?
  dogs               Dog[]
  pointWallet        PointWallet?
  recharges          PointRecharge[]
  inquiries          Inquiry[]
  courseUnlocks      CourseUnlock[]
  dailyGoal          DailyGoal?
  orders             Order[]
  notifications      Notification[]
  devices            Device[]
  createdAt          DateTime       @default(now())
  updatedAt          DateTime       @updatedAt

  @@index([deletedAt])
  @@map("User")
  @@schema("public")
}

enum UserStatus {
  ACTIVE
  SUSPENDED
  DELETED

  @@schema("public")
}

model Device {
  id         String         @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  userId     String         @db.Uuid
  user       User           @relation(fields: [userId], references: [id], onDelete: Cascade)
  platform   DevicePlatform // WEB = mobile-web 단독, ANDROID/IOS = shell 앱 (D14)
  pushToken  String         // FCM/APNs 토큰 (shell 앱 채널만 보유)
  appVersion String?
  osVersion  String?
  lastSeenAt DateTime       @default(now())

  @@unique([userId, pushToken])
  @@index([pushToken])
  @@map("Device")
  @@schema("public")
}

enum DevicePlatform {
  IOS
  ANDROID
  WEB

  @@schema("public")
}

model RefreshToken {
  id        String    @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  userId    String    @db.Uuid
  tokenHash String    @unique
  deviceId  String?   @db.Uuid
  expiresAt DateTime
  revokedAt DateTime?
  createdAt DateTime  @default(now())

  @@index([userId])
  @@map("RefreshToken")
  @@schema("public")
}
```

### 5.2 Dog / 일상기록 (유지 · 관계 개편)

```prisma
model Dog {
  id                String              @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid

  name              String
  birthDate         DateTime            @db.Date
  breedId           String?             @db.Uuid
  breed             Breed?              @relation(fields: [breedId], references: [id])
  sizeClass         SizeClass

  neutered          Boolean             @default(false)

  region            String?
  profileImage      String?
  grade             Int                 @default(1)   // 학년 — "교육 이수도" 파생 (구 월령 기반에서 전환, domain/dogs/grade.ts)
  anniversaries     Anniversary[]
  enrollments       Enrollment[]
  lessonProgresses  LessonProgress[]
  quizAttempts      QuizAttempt[]
  levelTestAttempts LevelTestAttempt[]
  surveyResponses   SurveyResponse[]

  badges            DogBadge[]
  vaccinations      VaccinationRecord[]
  dailyEntries      DailyEntry[]
  deletedAt         DateTime?
  createdAt         DateTime            @default(now())
  updatedAt         DateTime            @updatedAt

  @@index([userId, deletedAt])
  @@map("Dog")
  @@schema("public")
}

enum SizeClass {
  SMALL
  MEDIUM
  LARGE

  @@schema("public")
}

enum Gender {
  MALE
  FEMALE

  @@schema("public")
}

model Breed {
  id          String    @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  code        String    @unique   // 예: "POODLE_TOY"
  nameKo      String
  nameEn      String
  defaultSize SizeClass
  dogs        Dog[]

  @@map("Breed")
  @@schema("public")
}

model Anniversary {
  id    String   @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  dogId String   @db.Uuid
  dog   Dog      @relation(fields: [dogId], references: [id], onDelete: Cascade)
  label String   // "입양일" 등
  date  DateTime @db.Date

  @@map("Anniversary")
  @@schema("public")
}

// 일상기록 (보조 기능, 포인트 미연동 — D1)
// 접종 기록, 산책 유무(단순 체크), 사진 업로드, 자유 텍스트. GPS/경로 트래킹 없음.
model DailyEntry {
  id        String              @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  dogId     String              @db.Uuid
  dog       Dog                 @relation(fields: [dogId], references: [id], onDelete: Cascade)
  date      DateTime            @db.Date
  walked    Boolean             @default(false)  // 산책 유무 단순 체크 (구 Walk 세션 대체)
  memo      String?
  stickers  DailyEntrySticker[]
  createdAt DateTime            @default(now())
  updatedAt DateTime            @updatedAt

  @@unique([dogId, date])
  @@map("DailyEntry")
  @@schema("public")
}

model DailyEntrySticker {
  id        String      @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  entryId   String      @db.Uuid
  entry     DailyEntry  @relation(fields: [entryId], references: [id], onDelete: Cascade)
  kind      StickerKind
  note      String?
  photoUrl  String?     // 사진 업로드 (S3)
  createdAt DateTime    @default(now())

  @@map("DailyEntrySticker")
  @@schema("public")
}

enum StickerKind {
  POOP
  MEAL
  MEDICINE
  HOSPITAL
  WALK
  CUSTOM

  @@schema("public")
}
```

의료 기록(`VaccineType`/`VaccinationRecord`)은 현행 `schema.prisma` 정의를 그대로 유지한다 (변경 없음).

### 5.3 교육 커리큘럼 — Course / Unit / Lesson / LessonStep

콘텐츠 구조(§4.2): `Course → Unit → Lesson`, 레슨은 `영상 시청 → 실습(자가체크) → 최종퀴즈` 3단계(`LessonStep`)로 구성. 순차 잠금은 코스 내에서만 적용(D20). 초기 라인업 6~7개 코스, 약 100개 레슨(D22).

```prisma
model Course {
  id          String       @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  code        String       @unique          // "PUPPY_BASIC_101"
  title       String
  description String?
  level       Int          @default(1)      // 난이도 레벨 (레벨테스트·학년 산출 기준)
  coverImage  String?
  isPremium   Boolean      @default(false)  // true면 CourseUnlock 필요 (포인트샵 잠금해제 상품)
  isPublished Boolean      @default(false)  // 비공개 전환 시 기존 수강 진도는 보존
  order       Int          @default(0)
  units       Unit[]
  tags        CourseTag[]
  enrollments Enrollment[]
  levelTests  LevelTest[]
  unlocks     CourseUnlock[]
  createdAt   DateTime     @default(now())
  updatedAt   DateTime     @updatedAt

  @@index([isPublished, order])
  @@map("Course")
  @@schema("public")
}

model Unit {
  id       String   @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  courseId String   @db.Uuid
  course   Course   @relation(fields: [courseId], references: [id], onDelete: Cascade)
  title    String
  order    Int      @default(0)
  lessons  Lesson[]

  @@unique([courseId, order])
  @@map("Unit")
  @@schema("public")
}

model Lesson {
  id         String           @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  unitId     String           @db.Uuid
  unit       Unit             @relation(fields: [unitId], references: [id], onDelete: Cascade)
  title      String
  summary    String?
  order      Int              @default(0)   // 순차 잠금 판정 순서
  steps      LessonStep[]
  progresses LessonProgress[]
  createdAt  DateTime         @default(now())
  updatedAt  DateTime         @updatedAt

  @@unique([unitId, order])
  @@map("Lesson")
  @@schema("public")
}

// 레슨 구성 단계 — VIDEO / PRACTICE / QUIZ 각 1개 (타입별 페이로드는 하위 테이블)
model LessonStep {
```

### 5.9 포인트 — PointWallet / PointLedger / PointRecharge (D3, D7, D15, D21)

적립/차감은 기존 원칙 유지 — 단일 Postgres 트랜잭션:

1. `SELECT ... FOR UPDATE`로 `PointWallet` 행 잠금
2. `PointLedger` insert (차감 시: 적립 건 FIFO `remaining` 소진 update 포함)
3. `PointWallet.balance` 갱신
4. 커밋

호출 경로는 `point-settler` 큐 단일화 (lesson 이벤트, recharge webhook, inquiry 차감/환불, 주문, 만료 배치).

```prisma
model PointWallet {
  userId    String   @id @db.Uuid
  user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  balance   Int      @default(0)      // 집계 캐시 — 진실 공급원은 원장
  updatedAt DateTime @updatedAt

  @@map("PointWallet")
  @@schema("public")
}

// 원장 (append-only)
model PointLedger {
  id           String      @id @default(dbgenerated("uuid_generate_v7()")) @db.Uuid
  userId       String      @db.Uuid
  dogId        String?     @db.Uuid   // 교육 적립 건: 어느 강아지의 활동인지 기록 (FK 미선언 — 원장 보존)

  balanceAfter Int
  reason       PointReason
  refType      String?                // 'lesson'|'unit'|'course'|'recharge'|'order'|'inquiry'|'course_unlock'|'admin_adjust'
  refId        String?     @db.Uuid
  memo         String?
  // D21 포인트 유효기간 — 적립(+) 건에만 사용
  expiresAt    DateTime?              // 적립일 + point.expire_days(365일)
  remaining    Int?                   // FIFO 소진 잔여량 (적립 건만, 차감/만료 시 감소)
  createdAt    DateTime    @default(now())

  @@index([userId, createdAt])
  @@index([userId, expiresAt])
  @@map("PointLedger")
  @@schema("public")
}

enum PointReason {
  EARN_EDUCATION_WATCH     // 영상 시청완료 (P_watch)
  EARN_EDUCATION_PRACTICE  // 실습 성공 (P_practice)
  EARN_EDUCATION_QUIZ      // 퀴즈 통과 (P_quiz)
  EARN_BONUS_UNIT          // 유닛 완주 보너스
  EARN_BONUS_COURSE        // 코스 완주 보너스
  EARN_RECHARGE            // 현금 충전 (PG/IAP)
  SPEND_SHOP               // 포인트샵 주문
  SPEND_INQUIRY            // 훈련사 문의권
  SPEND_COURSE_UNLOCK      // 프리미엄 콘텐츠 잠금해제
  REFUND                   // 환불 (주문 취소, Inquiry SLA 초과/취소)
  EXPIRE                   // 유효기간 만료 소멸 (배치)
  ADMIN_GRANT
  ADMIN_REVOKE

  @@schema("public")
}
```

**FIFO 소멸 규칙 (D21)**

- 적립(+) 건은 `expiresAt = createdAt + point.expire_days`, `remaining = delta`로 생성. 충전(`EARN_RECHARGE`) 건도 동일 적용(환불 정책은 §10 미확정 2번).
- 차감(-) 시 `remaining > 0`인 적립 건을 `expiresAt` 오름차순(선입선출)으로 소진.
- worker의 만료 배치가 `expiresAt < now() AND remaining > 0` 건을 스캔해 `EXPIRE` 차감 원장을 생성하고 `remaining = 0` 처리.
- 소멸 30일/7일 전 `notification-dispatcher`로 예정 알림 발송.

### 6.2 공간 인덱스 — 제거

산책 기능 폐기(D1)로 `walk_path_gix`(GIST) 및 `geography` 컬럼이 사라진다. **PostGIS 확장 자체를 제거 가능** — 위치기반 커뮤니티(2차, §10 미확정 6번)는 네이버맵 JS API v3 기반 클라이언트 처리라 서버 공간 데이터가 불필요하다. 제거 절차는 §8.

### 6.3 Soft Delete 전략 — Partial Index + Prisma 미들웨어 (기존 유지)

Soft delete는 `deletedAt DateTime?` 컬럼(nullable timestamp)을 사용한다(`use_yn` 패턴 금지). **Partial Index**와 **Prisma 미들웨어** 두 레이어로 보호하며, 피벗과 무관하게 그대로 유지한다.

**Partial Index** — 삭제된 행을 인덱스에서 제외해 활성 레코드 조회 성능을 유지한다.

```sql
-- migration.sql에 수동 추가 (prisma migrate가 자동 생성하지 않음)
CREATE INDEX IF NOT EXISTS user_active_idx          ON "User" (id)        WHERE "deletedAt" IS NULL;
CREATE INDEX IF NOT EXISTS user_active_nickname_idx ON "User" (nickname)  WHERE "deletedAt" IS NULL;
CREATE INDEX IF NOT EXISTS dog_active_by_user_idx   ON "Dog"  ("userId")  WHERE "deletedAt" IS NULL;
```

**Prisma 미들웨어** — `packages/prisma/src/middleware/softDelete.ts`가 `User`, `Dog`의 read 액션(`findMany`/`findFirst`/`count` 등)에 `deletedAt: null` 조건을 자동 주입한다. 서비스 코드에서 수동으로 조건을 추가하지 말 것.

> **주의**: 관리자 콘솔에서 탈퇴 회원을 명시적으로 조회할 때만 `where: { deletedAt: { not: null } }`을 직접 지정한다. `update`나 원장 보존 쿼리에는 미들웨어가 영향을 주지 않는다.

PostGIS 제거는 마지막에 별도 확인 후 실행: `DROP EXTENSION postgis;` — 의존 객체(Walk 계열)가 STEP 2에서 모두 제거되었으므로 성공해야 정상. 실패 시 잔존 의존 객체를 점검한다.

**STEP 6 — 검증**: `prisma migrate diff`로 스키마 정합 확인 → backup 스키마 row count 대조 → 서비스 계정으로 backup 스키마 접근 불가 확인(`SELECT`가 permission denied여야 정상)

## 10. 오픈 이슈 (스펙 §10과 연동)

1. **정책 초기값**: §4 카탈로그의 런칭 초기값 미정 — 포인트 이코노미 시뮬레이션 후 세팅.
2. **환불 정책**: 충전 포인트 환불(PG/IAP 각각) 시 원장 처리 규칙 — `EARN_RECHARGE` 건 `remaining` 잔여분만 환불? 만료분 처리?
3. **Q&A 배정 방식**: 관리자 수동 vs `TrainerTag` 기반 자동 — `Inquiry.trainerId` nullable로 양쪽 수용 가능하게 설계됨.
4. **레벨테스트 문항**: `LevelTest.questions`(Json) 구조는 `QuizQuestion`과 동일 형식 권장 — 문항 설계 후 정규화(별도 테이블) 여부 재검토.
5. **문의권 크레딧 방식**: MVP는 문의 시 직접 차감. `INQUIRY_TICKET` 선구매 크레딧 도입 시 `InquiryTicket` 보유 테이블 추가 필요.
6. **Q&A 영상 보존 기간**: 답변 완료 후 S3 원본/HLS 보존 기간 및 삭제 배치.
7. **위치기반 커뮤니티(2차)**: 네이버맵 JS API 기반이라 서버 공간 데이터 불필요 전제 — 상세 기획에서 서버 측 장소 데이터 필요성이 생기면 PostGIS 재도입이 아닌 외부 API(네이버 지역검색) 우선 검토.
