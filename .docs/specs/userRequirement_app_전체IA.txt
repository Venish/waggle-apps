📱 전체 IA (Information Architecture)


1️⃣ 전체 앱 IA (Information Architecture)

APP
├─ 온보딩
 │   ├─ 앱 소개
 │   ├─ 회원가입 / 로그인
 │   ├─ 반려견 등록
 │   └─ 권한 요청 (위치 / 알림)
 ├─ 홈 (강아지 수첩 캘린더)
 │   ├─ 오늘 요약
 │   ├─ 캘린더
 │   ├─ 산책 기록
 │   ├─ 교육 일정
 │   ├─ 미션 진행
 │   └─ 배변/건강 스티커 기록
 ├─ 산책
 │   ├─ 산책 시작
 │   ├─ 산책 진행 지도
 │   ├─ 산책 종료 결과
 │   └─ 산책 기록 목록
 ├─ 교육
 │   ├─ 교육 과정 목록
 │   ├─ 교육 상세
 │   ├─ 교육 영상 시청
 │   └─ 교육 완료 체크
 ├─ 미션 / 뱃지
 │   ├─ 미션 목록
 │   ├─ 진행 미션
 │   └─ 뱃지 컬렉션
 ├─ 포인트샵
 │   ├─ 상품 목록
 │   ├─ 상품 상세
 │   ├─ 장바구니
 │   ├─ 주문결제
 │   ├─ 배송정보 입력
 │   └─ 주문 완료
 ├─ 알림
 │   ├─ 읽은 알림
 │   └─ 안 읽은 알림
 └─ 마이
     ├─ 내 반려견
     ├─ 내 미션
     ├─ 주문 내역
     ├─ 알림 설정
     ├─ 포인트
     │   ├─ 포인트 지갑
     │   ├─ 적립 내역
     │   └─ 사용 내역
     └─ 앱 설정
     

2️⃣ 네비게이션 구조
상단 : [페이지명]          1,000P [알림][마이]
본문 : 콘텐츠 영역
하단 : [홈] [교육] [산책][미션] [포인트샵]

* 하단 메뉴 역할
홈 :	강아지 캘린더
교육	: 반려견 교육 프로그램
산책	: GPS 산책 기록
미션	: 미션 진행 내역 / 미션 목록 / 완료 목록
포인트샵	: 리워드 소비

* 상단 메뉴 역할
알림 : 받은 알림 리스트 
마이	: 개인 설정
