## 1. 백엔드 공통 (MAPI / AAPI / Worker)

### 1.1 런타임 / 언어

| 항목 | 선택 | 비고 |
|---|---|---|
| 런타임 | **Node.js 22 LTS** | 2026년 10월까지 Active LTS |
| 언어 | **TypeScript 5.7+** | strict 모드, `noUncheckedIndexedAccess` 활성화 |
| 패키지 매니저 | **pnpm 9** | 모노레포 워크스페이스 |
| 빌드 오케스트레이션 | **Turborepo 2** | 원격 캐시는 MVP 이후 |

### 1.2 웹 프레임워크

| 항목 | 선택 | 비고 |
|---|---|---|
| 프레임워크 | **NestJS 10** | 공식 구조, DI, 모듈 시스템 |
| HTTP 어댑터 | **Fastify 4** | `@nestjs/platform-fastify` |
| 라우팅/검증 | `@nestjs/swagger` + `class-validator` + `class-transformer` | OpenAPI 자동 생성 |
| ORM | **Prisma 6** | PostgreSQL, 타입 안정성 |
| 로거 | **Pino** | Fastify 기본, JSON 로그 |
| 설정 | `@nestjs/config` + Zod 스키마 검증 | `env.schema.ts`로 필수 키 강제 |
| 스케줄러 | `@nestjs/schedule` + BullMQ | 주기 작업은 BullMQ repeat job 우선 |
| 이벤트 버스 | `@nestjs/event-emitter` (인프로세스) + BullMQ (크로스프로세스) | |

### 1.3 인증 / 인가

| 항목 | 선택 | 비고 |
|---|---|---|
| JWT | `@nestjs/jwt` + `jsonwebtoken` (HS256 MVP, RS256 프로덕션) | Access 15min / Refresh 30d |
| 패스워드 해시 | **Argon2id** (`argon2`) | bcrypt 대신 OWASP 권장 |
| 소셜 로그인 | `passport` + 각 Strategy | 카카오·네이버는 passport-oauth2 커스텀, Google은 `passport-google-oauth20`, Apple은 `passport-apple` |
| RBAC | 커스텀 `@Roles()` + `RolesGuard` | 관리자(AAPI) 전용 |
| 2FA (관리자, 2차) | `speakeasy` + QR | TOTP |
| Rate Limiting | `@nestjs/throttler` + Redis 스토어 | IP + userId 조합 |

### 1.4 비동기 작업

| 항목 | 선택 | 비고 |
|---|---|---|
| 큐 | **BullMQ 5** | Redis 7 기반 |
| 워커 | 별도 NestJS 앱(`apps/worker`) | 확장은 워커 수평 증설 |
| 주요 큐 | `mission-evaluator`, `notification-dispatcher`, `video-postprocess`, `order-fulfillment`, `point-settler` | |

### 1.5 DB / 마이그레이션

| 항목 | 선택 | 비고 |
|---|---|---|
| RDB | **PostgreSQL 16** + **PostGIS 3.4** | 공간 인덱스 |
| 마이그레이션 | `prisma migrate` | dev/prod 별도 적용, shadow DB 사용 |
| 시드 | `prisma/seed.ts` | 초기 교육 커리큘럼, 상품 카테고리, 관리자 계정 |
| 풀링 | Prisma 기본 풀 + **PgBouncer**(선택, 고동시성 시) | Serverless 환경 아님 → MVP는 불필요 |
| 읽기 전용 복제 | PostgreSQL streaming replication | 통계/관리자 조회는 R/O 노드 |

### 1.6 테스트

| 계층 | 도구 | 대상 |
|---|---|---|
| 단위 | **Vitest** | 도메인 계산 로직(포인트, 미션 조건, 월령 계산) |
| 통합 | Vitest + **Testcontainers** (PostgreSQL/Redis) | Prisma 레포 계층, 서비스 계층 |
| E2E (API) | **Supertest** | MAPI/AAPI 컨트롤러 |
| 부하 | **k6** | 산책 세션 종료, 포인트샵 결제 |

### 1.7 보안

- `helmet` (Fastify 플러그인)
- CORS: 앱은 네이티브 → CORS 불필요. 관리자 웹만 허용 origin 등록.
- 요청 바디 크기 제한: JSON 2MB, 이미지는 presigned PUT으로 S3 직접 업로드
- SQL Injection: Prisma 파라미터 바인딩
- XSS: Next.js 기본 이스케이프 + DOMPurify(관리자 리치텍스트 에디터)
- CSRF: 관리자 웹은 쿠키 + CSRF 토큰, 모바일은 Bearer JWT (CSRF 불필요)
- 감사 로그(admin): 모든 쓰기 액션 `admin_audit_log`에 before/after 저장

### 2.3 앱 설계 원칙

1. **서버 상태는 TanStack Query**, 로컬 UI 상태는 Zustand
2. **Optimistic UI**: 포인트 적립/미션 수령 팝업은 서버 응답 전에 낙관적 표시 후 실패 시 롤백
3. **오프라인 퍼스트(산책 기록)**: 산책 중 네트워크 불안정 시 로컬 저장(MMKV) → 복구 시 업로드
4. **Deep Link 라우팅 테이블**: 푸시/외부 링크 → 화면 매핑을 `packages/deeplinks`로 공용화
5. **접근성**: VoiceOver/TalkBack 레이블 제공 (교육 콘텐츠는 자막 필수)

## 5. 개발 환경

### 5.1 로컬

- `docker compose`로 PostgreSQL(+PostGIS), Redis, MinIO(S3 호환) 기동
- `.env.local` 자동 로드 (`dotenv-flow`)
- `pnpm dev` → Turborepo가 MAPI/AAPI/Admin Web을 병렬 실행
- 모바일은 `pnpm --filter mobile-app ios` / `android`

### 5.2 코드 품질

| 도구 | 역할 |
|---|---|
| **ESLint 9** (flat config) | 린트 |
| **Prettier 3** | 포매팅 |
| **Husky** + **lint-staged** | pre-commit |
| **Commitlint** (Conventional Commits) | 커밋 메시지 규칙 |
| **Changesets** | 패키지 버전/체인지로그 |
| **TypeScript Project References** | 증분 타입체크 |

### 5.3 브랜치 전략

- `main`: 항상 배포 가능. 머지 시 staging 자동 배포.
- `develop`(선택): 필요 시 feature 집결용. MVP는 `main` 단일 트렁크 + feature branch PR.
- `feature/*`, `fix/*`, `release/*`, `hotfix/*`
- PR 머지 조건: 1명 이상 리뷰 + CI 통과 + 관련 테스트 추가

## 7. 오픈 이슈

1. **NativeWind vs Unistyles**: NativeWind 권장이나, 특정 네이버지도 뷰가 Tailwind 클래스와 충돌 시 Unistyles 재검토.
2. **배경 위치 추적**: iOS 백그라운드 fetch 제약 → 전용 유료 SDK(react-native-background-geolocation transistorsoft) 여부 결정 필요. MVP는 **포그라운드 전용 추적**으로 시작 가능.
3. **영상 DRM**: 유료 교육 콘텐츠 도입 시 HLS FairPlay/Widevine 필요. MVP는 DRM 없이.
4. **관리자 2FA**: MVP 범위 제외, v1.1에서 도입.
