[Waggle 서비스 기능정의서]

* 핵심 아이디어
반려견 산책 로그와 교육서비스를 미션형태로 제공하여 재미요소를 더하고, 미션 달성시 포인트를 지급하여 리워드를 받을수 있게 하는 서비스이다. 
즉, “강아지수첩(캘린더) 중심 → 교육 + 산책 기록 연계 → 미션달성(포인트 지급) → 리워드(포인트샵)”

1️⃣ 서비스 구조 재정의 (Core 구조)
🎯 메인 허브: “강아지 수첩 (캘린더 기반 라이프 로그)”

[강아지 수첩]
 ├─ 출석
 ├─ 교육 일정
 ├─ 산책 기록
 ├─ 의료 기록
 ├─ 미션
 ├─ 리워드
👉 사용자는 매일 “수첩”을 열게 만드는 구조
👉 모든 기능은 수첩 안에서 연결

2️⃣ 구현 가능한 기능 리스트 (MVP 중심)
🐶 1. 반려견 프로필 등록
기능
	• 이름
	• 생년월일
	• 견종
	• 체중
	• 성별
	• 중성화 여부
	• 거주 지역 (지자체 서비스 연계용)
활용
	• 월령 계산 자동화
	• 견종/체급별 교육 커리큘럼 자동 세팅
	• 예방접종 알림 자동 세팅
	• 광견병 지자체 안내

📘 2. 강아지 수첩 (캘린더 중심 UI)
월간 캘린더
표시 항목:
	• ✅ 출석
	• 🎓 교육일
	• 🐾 산책 기록
	• 💉 예방접종
	• 💩 배변/건강 스티커
	• 🏆 미션 달성일
일간 상세 페이지
선택 날짜 클릭 시:
	• 출석 여부
	• 교육 수강 여부
	• 산책 거리
	• 의료 기록
	• 메모

🎓 3. 생애주기 교육 시스템
교육 커리큘럼 구조
기준:
	• 월령
	• 체급 (소/중/대형)
	• 생애주기 단계
교육 종류
	1. 기본 사회화 교육
	2. 산책 매너 교육
	3. 문제행동 대응 교육
	4. 상황별 대처 교육
기능 구현
	• 월령 도달 시 자동 노출
	• 푸시 알림
	• 동영상 플레이어
	• 수강 완료 체크
	• 퀴즈 or 확인 버튼
	• 포인트 지급
주제별 교육 커리큘럼
	* 생애주기와 관계없이 특정 주제별 교육 커리큘럼 생성
	* 문제 행동 교정 교육
	* ex) 배변교육, 산책교육, 입질 교육 등

🐾 4. 산책 기록 시스템
필수 기능
	• GPS 기반 경로 추적
	• 거리(km)
	• 시간
	• 평균 속도
	• 지도 저장
선택 기능 (2차)
	• 산책 사진 업로드
	• 메모
	• 즐겨찾기 산책코스

🏆 5. 미션 시스템
자동 달성 조건
	• 10일 연속 출석
	• 산책 50km
	• 산책 100km
	• 교육 5개 완료
	• 1년 광견병 접종 완료
리워드
	• 포인트
	• 교재 배송권 ( 포인트로 구매? )

💰 6. 포인트 시스템
포인트 획득 경로
	• 출석
	• 교육 이수
	• 미션 달성
	• 산책 거리 누적
사용처(포인트 샵)
	• 교재 구매
	• 기업 연계 쿠폰
	• 굿즈 교환

💉 7. 의료 알림 기능
	• 광견병 (연 1회) - 사용자가 입력한 강아지 접종 정보 또는 생일 정보를 바탕으로 1년후에 알림 발송
	• 종합백신 - 사용자가 입력 하게 하되 기본 백신 정보에 대한 가이드 제공
	• 구충
	• 심장사상충 - 매월 알림 발송
	* 광견병 접종에 관해 지역 기반 정보 알림 ( 경기도 무상지원 및 접종 가능 병원 알림 )

3️⃣ 기능 구체화 (정책 설계 레벨)
🎓 교육 정책 예시

0~3개월 : 사회화 집중
3~6개월 : 기본 복종
6~12개월 : 산책 매너
1년 이후 : 문제행동/심화
교육은 “과목” 형태로 설계:

과목
 ├─ 단원
 ├─ 영상
 ├─ 퀴즈
 ├─ 완료 체크

🐾 산책 기록 데이터 설계 개념
산책 세션:
	• 시작시간
	• 종료시간
	• 총 거리
	• 경로 Polyline
	• 평균속도
	• 포인트 계산
포인트 공식 예시: 1km = 10포인트

🏆 미션 시스템 로직 구조
미션은 조건 기반 이벤트 시스템으로 설계:

condition_type
- attendance_streak
- walk_distance_total
- education_complete_count
- vaccine_check
백엔드에서 자동 검증 → 달성 시 알림 → 포인트 지급
