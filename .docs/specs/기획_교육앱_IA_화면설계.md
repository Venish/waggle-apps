## 1. 개요

- 컨셉: **"듀오링고처럼, 우리 강아지에게 맞는 커리큘럼으로 매일 조금씩 교육하고 기록한다."**
- 플랫폼(D14): `apps/mobile-web`(Next.js 모바일웹) 우선 + Android/iOS 네이티브 shell(WebView + 푸시). 본 문서의 화면은 모바일웹 기준이며, shell에서는 동일 화면 + 네이티브 푸시/탭바(iOS)만 추가된다.
- 산책 GPS 기능은 전면 제거(D1). 일상기록(캘린더)이 보조 기능으로 유지된다.
- 총 화면 수: **52개** (섹션 §4, 화면 ID 기준)

## 2. 전체 IA (Information Architecture)

### 2.1 내비게이션 구조

```
상단 : [페이지명]                 1,240P  [알림🔔] 
본문 : 콘텐츠 영역
하단 : [홈] [교육기록] [일상기록] [포인트샵] [마이]
```

| 하단 탭 | 역할 |
|---|---|
| **홈** | 커리큘럼 경로(듀오링고식 노드 맵) — 레슨 수강의 시작점 |
| **교육기록** | 강아지별 진도 대시보드 · 배지 컬렉션 · 강아지 학년(레벨) |
| **일상기록** | 캘린더 — 접종·산책유무·사진·자유기록 (포인트 미연동) |
| **포인트샵** | 실물 제휴상품 · 훈련사 문의권 · 프리미엄 콘텐츠 |
| **마이** | 포인트 지갑/충전, 훈련사 Q&A, 강아지·알림·앱 설정 |

- 상단 우측: 보유 포인트(탭하면 포인트 지갑 PNT-01), 알림 센터(NTF-01)
- 다견 계정: 상단 좌측 강아지 스위처(아바타 탭 → 강아지 전환). 홈/교육기록/일상기록은 **선택된 강아지 기준**으로 렌더링(진도는 Dog 기준, D24)

### 2.2 화면 트리 전체

```

│   ├─ 강아지 프로필 등록 (ONB-04)

│   ├─ 커리큘럼 추천 결과 (ONB-06)
│   ├─ 레벨테스트 안내 (ONB-07)
│   ├─ 레벨테스트 진행 (ONB-08)
│   ├─ 레벨테스트 결과 (ONB-09)
│   └─ 데일리 목표 설정 (ONB-10)
├─ 홈 (커리큘럼 경로)
│   ├─ 커리큘럼 경로 — 노드 맵 (HOM-01)
│   ├─ 코스 탐색/전환 (HOM-02)
│   └─ 코스 소개 — 미수강 코스 (HOM-03)
├─ 레슨 루프
│   ├─ 레슨 상세 (LSN-01)
│   ├─ 영상 플레이어 — YouTube iframe (LSN-02)
│   ├─ 실습 자가체크 (LSN-03)
│   ├─ 최종퀴즈 (LSN-04)
│   ├─ 퀴즈 결과 / 레슨 완료 (LSN-05)
│   └─ 완주 축하 — 유닛/코스, 배지·학년 승급 (LSN-06)
├─ 교육기록
│   ├─ 교육기록 홈 — 진도 대시보드 (REC-01)
│   ├─ 배지 컬렉션 (REC-02)
│   └─ 강아지 학년/레벨 상세 (REC-03)
├─ 일상기록
│   ├─ 캘린더 (DLY-01)
│   ├─ 일자 상세 (DLY-02)
│   └─ 기록 작성/수정 (DLY-03)
├─ 포인트샵
│   ├─ 포인트샵 홈 (SHP-01)
│   ├─ 상품 목록 — 카테고리 (SHP-02)
│   ├─ 상품 상세 — 실물 (SHP-03)
│   ├─ 상품 상세 — 디지털: 문의권/프리미엄 (SHP-04)
│   ├─ 장바구니 (SHP-05)
│   ├─ 주문/배송정보 입력 (SHP-06)
│   ├─ 주문 완료 (SHP-07)
│   └─ 주문 내역 (SHP-08)
├─ 포인트
│   ├─ 포인트 지갑 (PNT-01)
│   ├─ 포인트 충전 — 채널 분기 (PNT-02)
│   └─ 충전 결과 (PNT-03)
├─ 훈련사 Q&A
│   ├─ 문의 목록 (QNA-01)
│   ├─ 문의 작성 — 영상 업로드 (QNA-02)
```

## 3. 주요 사용자 플로우

### 3.1 온보딩 (신규 가입 → 첫 레슨 진입 가능 상태)

```
ONB-01 스플래시
  → ONB-02 로그인 (소셜: 카카오/애플/구글 · 이메일)
  → [신규] ONB-03 회원가입/약관 동의
  → ONB-04 강아지 프로필 등록 (이름·견종·생년월·성별·중성화·체중)
      · 월령/견종은 자동 태그화(puppy/adolescent/adult/senior) — 설문에서 제외 (§4.1.1)
  → ONB-05 설문 인트로
  → SUR-01 ~ SUR-07 설문 7문항 (전부 객관식 · 비분기 · 문항당 1화면, D17)
      · 2번 문항만 복수 선택, 나머지 단일 선택
  → [서버] 룰 기반 태그 매칭 (답변 태그 ↔ 코스 태그 점수 계산, D9)
  → ONB-06 커리큘럼 추천 결과 (점수순 추천 코스 카드)
      → "이 코스로 시작" 선택 시 Enrollment 생성
  → [선택 분기] "우리 강아지는 이미 배웠어요"
      → ONB-07 레벨테스트 안내 → ONB-08 진행(4지선다) → ONB-09 결과
      · 통과 레벨 이하 레슨 일괄 이수 처리 → 상위 단계부터 시작 (D5)
      · 건너뛰기 가능 (레벨테스트는 어디까지나 선택)
  → ONB-10 데일리 목표 설정 (1일 레슨 수 + 리마인드 푸시 시간대)
      · 기본값은 설문 4번(하루 교육 가능 시간) 답변으로 프리셋
  → HOM-01 홈 커리큘럼 경로 진입 (첫 레슨 하이라이트 + 시작 유도 툴팁)
```

### 3.2 레슨 루프 (핵심 수강 흐름)

```
HOM-01 커리큘럼 경로에서 "현재" 노드 탭
  → LSN-01 레슨 상세 (개요 · 3단계 스텝 표시: 영상 → 실습 → 퀴즈)
  → LSN-02 영상 플레이어 (YouTube IFrame Player API 임베드, D6)
      · 진도 이벤트로 시청률 추적 — 95% 이상 시청 시 완료, 배속 허용 (D19)
      · 완료 순간: "+P_watch" 포인트 적립 연출 ①  ← 낙관적 UI, 서버 확정은 point-settler
  → LSN-03 실습 자가체크 (체크리스트 항목 전부 체크 → "실습 성공")
      · 성공 순간: "+P_practice" 포인트 적립 연출 ②
  → LSN-04 최종퀴즈 (4지선다 3~5문항, 통과 기준 관리자 설정, D18)
      · 문항별 즉시 정오 피드백 → 마지막 문항 후 채점
  → LSN-05 퀴즈 결과
      · 통과: "+P_quiz" 포인트 적립 연출 ③ + 레슨 완료 처리 + 다음 레슨 잠금 해제
      · 불통과: 오답 해설 + [다시 풀기] (재시도 무제한, 포인트는 최초 통과 1회만)
  → [유닛/코스 마지막 레슨이면] LSN-06 완주 축하
      · 완주 보너스 포인트 + 배지 획득 + (조건 충족 시) 강아지 학년 승급 연출 (D8·D20)
  → HOM-01 복귀 — 완료 노드에 체크 표시, 다음 노드가 "현재" 상태로 활성화
      · 데일리 목표 달성 시 상단에 목표 달성 뱃지 표시
```

포인트 3회 적립은 각 레슨당 **최초 1회만** 지급(D7). 이미 지급된 단계 재수행 시 적립 연출 없이 완료 상태만 표시.

### 3.3 훈련사 영상 Q&A (비동기, D4)

```
MY-01 마이 → "훈련사 Q&A" 또는 QNA-01 문의 목록 → [새 문의]
  → [문의권 확인]
      · 보유 문의권 있음 → 작성 진입
      · 없음 → "문의권이 필요해요" 시트 → SHP-04 문의권 구매로 이동
  → QNA-02 문의 작성
      · 문제 행동 영상 업로드 (≤N분, file input capture — 촬영/앨범 선택)
      · 질문 텍스트 작성 · 대상 강아지 선택 · 분야 태그 선택
  → [제출] 문의권(포인트) 차감 — 단일 트랜잭션, 차감 확인 다이얼로그
  → QNA-01 목록에 "답변 대기" 상태로 표시 (SLA 48시간 카운트다운)
      · 48h 초과 시 자동 환불(포인트 복구) + 알림 (inquiry-sla-watcher)
  → [훈련사 답변 등록] → 푸시 알림 "훈련사 답변이 도착했어요" 수신
  → NTF-01 알림 탭 or QNA-01 → QNA-03 문의 상세 (답변 텍스트/영상 열람)
  → 별점 평가 (1~5점, 1회) — 훈련사 노출 순위 반영은 2차
```

### 3.4 포인트 충전 — 채널 분기 (D10·D15)

```
PNT-01 포인트 지갑 → [충전하기] → PNT-02 포인트 충전
  → [런타임 채널 감지] 웹 브라우저인가, 네이티브 shell(WebView)인가?

  (A) 모바일웹 (브라우저 직접 접속)
      → 충전 패키지 목록: 웹 가격 표시 (예: 10,000원 = 10,000P)
      → PortOne 결제창 (카드/간편결제)
      → 결제 완료 webhook → 포인트 적립 → PNT-03 충전 결과

  (B) 앱 (Android/iOS shell 내 WebView)
      → 충전 패키지 목록: IAP 가격 표시 (예: 12,000원 = 10,000P)
      → shell 브릿지 호출 → 스토어 IAP 결제 시트
      → 영수증 서버 검증 → 포인트 적립 → PNT-03 충전 결과

  ⚠ 준수 사항 (D15 / §9 IAP 리스크):
    · 앱 내에서 웹 가격 노출·안내·유도(스티어링) 절대 금지
      — 가격표·배너·문구·푸시 전부 해당. 채널별로 패키지 데이터 자체를 분리 응답
    · 앱 내 WebView에서 PortOne 결제창 노출 금지 (진입 시점에 채널 분기)
    · 충전분/적립분은 원장에서 구분 관리 (환불·정산 대비)
```

## 4. 화면별 설계

각 화면은 **구성 요소 / 상태 / 주요 인터랙션** 3항목으로 기술한다. 공통 상태 규칙:

- **로딩**: 스켈레톤 UI 기본 (스피너는 전체 화면 전환에만)
- **에러**: 인라인 재시도 버튼 + 토스트. 네트워크 단절 시 오프라인 배너
- **빈 상태**: 캐릭터 일러스트 + 행동 유도 CTA (단순 "데이터 없음" 문구 금지)
- 포인트 적립 연출: 낙관적 UI(즉시 표시) → 서버 확정 실패 시 롤백 토스트

### 4.1 온보딩

#### ONB-01 스플래시
- **구성**: 로고 + 강아지 캐릭터, 버전/세션 체크
- **상태**: 로딩(기본) / 강제 업데이트 다이얼로그 / 점검 안내
- **인터랙션**: 자동 분기 — 세션 유효 → HOM-01, 무효 → ONB-02. 온보딩 미완료(설문 중단 등) 계정은 중단 지점으로 복귀

#### ONB-02 로그인
- **구성**: 앱 소개 카피 + 캐릭터, 소셜 로그인 버튼(카카오/애플/구글), 이메일 로그인, [이메일로 가입]
- **상태**: 로딩(버튼 스피너) / 소셜 인증 실패 토스트 / 탈퇴 계정 안내
- **인터랙션**: 소셜 토큰은 최초 프로필 조회 후 폐기(서버 보관 금지). 신규 소셜 계정이면 ONB-03 약관으로

#### ONB-03 회원가입/약관 동의
- **구성**: 약관 체크리스트(필수/선택 — 마케팅 수신), 이메일 가입 시 이메일/비밀번호 폼
- **상태**: 유효성 인라인 에러 / 중복 이메일 안내
- **인터랙션**: 필수 약관 전체 동의 시 [다음] 활성화 → ONB-04

#### ONB-04 강아지 프로필 등록
- **구성**: 진행 표시(1/3 프로필), 사진(선택), 이름, 견종(검색 셀렉트, Breed 마스터), 생년월(월 단위 피커), 성별, 중성화 여부, 체중
- **상태**: 필수값 미입력 시 [다음] 비활성 / 견종 검색 결과 없음 → "믹스/모름" 옵션
- **인터랙션**: 생년월 입력 시 월령 자동 계산·표시("생후 7개월, 청소년기예요") → 연령 태그 자동 부여. 완료 → ONB-05

#### ONB-05 설문 인트로
- **구성**: 캐릭터 + "{강아지이름}에게 딱 맞는 수업을 찾아볼게요" 카피, 소요 안내(7문항, 1분), [시작하기], [건너뛰기(나중에)]
- **인터랙션**: 건너뛰기 시 기본 커리큘럼(연령 태그만으로 추천) 제공, 마이에서 재설문 가능

- **구성(공통)**: 상단 진행바(n/7), 질문 1개, 선택지 버튼 목록(카드형), [다음]([이전]으로 되돌아가기 가능)

  - SUR-02 고치고 싶은 행동 (**복수 선택** — 선택 개수 뱃지 표시, "없음" 선택 시 나머지 해제)
  - SUR-03 교육 목표 (단일)
  - SUR-04 하루 교육 가능 시간 (단일 — 데일리 목표 기본값으로 사용)
  - SUR-05 주거 환경 (단일)
  - SUR-06 사회성 반응 (단일)

- **인터랙션**: 중도 이탈 시 답변 로컬 저장 → 재진입 시 이어서. 마지막 문항 완료 → 매칭 계산 로딩("맞춤 커리큘럼을 만들고 있어요" 애니메이션) → ONB-06

#### ONB-08 레벨테스트 진행

- **상태**: 웹 채널에서 푸시 불가 시 "앱을 설치하면 알림을 받을 수 있어요" 안내(스토어 링크는 정책 확인 후)

### 4.6 포인트샵

기존 `userRequirement_app_포인트샵기능정의.txt`의 골격(홈/목록/상세/장바구니/주문/완료/내역, 포인트+현금 혼합 결제)을 유지하고, **디지털 상품(문의권·프리미엄) 유형을 추가**한다. 카테고리에서 "산책용품"은 "훈련용품"으로 대체.

#### SHP-01 포인트샵 홈
- **구성**: 상단 보유 포인트(항상 표시), 카테고리 타일(🎫 문의권 · 🔓 프리미엄 콘텐츠 · 📚 교재/교육키트 · 🦴 간식/사료 · 🧸 장난감/훈련용품 · 🎁 이벤트), 추천 상품 캐러셀, 배너
- **상태**: 로딩 스켈레톤 / 포인트 부족 사용자에게 "충전하기" 숏컷(단, **앱 채널에서는 가격 미노출** — PNT-02로만 연결)
- **인터랙션**: 카테고리 → SHP-02, 상품 → SHP-03/04

#### SHP-02 상품 목록
- **구성**: 카테고리 탭/칩, 정렬(포인트순·인기순), 상품 카드(이미지·상품명·포인트 가격·혼합 결제 시 "+n원" 표기)
- **상태**: 빈 카테고리 / 품절 상품 딤 처리
- **인터랙션**: 무한 스크롤, 카드 탭 → 상세

#### SHP-03 상품 상세 — 실물
- **구성**: 이미지 캐러셀, 상품명·가격(P + 현금 병기 가능), 상세 설명, 배송 정보, 수량 스테퍼, [장바구니 담기], [바로 구매]
- **상태**: 품절 → CTA 비활성 + 재입고 알림 신청 / 포인트 부족 → CTA "포인트가 부족해요" + 충전 유도(채널 준수)
- **인터랙션**: 바로 구매 → SHP-06, 담기 → 토스트 + 장바구니 뱃지 증가

#### SHP-04 상품 상세 — 디지털 (문의권 / 프리미엄 콘텐츠)
- **구성**: 상품 설명(문의권: 사용 방법·SLA 48h·유효기간 / 프리미엄: 해제되는 코스·레슨 미리보기), 포인트 가격(**포인트 단일 가격** — 채널 무관 동일, D15), [포인트로 구매]
- **상태**: 포인트 부족 → 부족분 표시 + [충전하러 가기](PNT-02) / 이미 보유(프리미엄 기해제) → "이용 중" 표시
- **인터랙션**: 구매 확인 시트(차감 후 잔액 미리보기) → 즉시 지급(배송 없음) → 문의권은 QNA-02로, 프리미엄은 해당 코스 HOM-01로 바로가기 제공

#### SHP-05 장바구니
- **구성**: 상품 행(체크박스·썸네일·수량 스테퍼·개별 삭제), 전체 선택/선택 삭제, 하단 결제 요약(포인트 합계 + 현금 합계)
- **상태**: 빈 장바구니 → "샵 둘러보기" CTA / 담은 후 품절된 상품 딤 + 안내
- **인터랙션**: [주문하기] → SHP-06. 디지털 상품은 장바구니 미경유(상세에서 즉시 구매)

#### SHP-06 주문/배송정보 입력
- **구성**: 배송지 폼(이름·전화·주소·상세주소, 기본 배송지 저장/불러오기), 주문 상품 요약, 결제 요약(상품 포인트 + 배송비/현금분), 보유·사용 포인트, 현금분 결제수단 선택
- **상태**: 필수값 검증 인라인 에러 / 결제 진행 중 이중 제출 방지 / 결제 실패 → 사유 표시 + 재시도
- **인터랙션**: 현금 혼합분 결제도 채널 분기 원칙 적용. [결제하기] → 포인트 차감(단일 트랜잭션) + PG 승인 → SHP-07

#### SHP-07 주문 완료
- **구성**: 완료 연출, 주문번호, 상품 요약, 배송 예정 안내, [주문 내역 보기], [계속 교육하기](HOM-01)
- **인터랙션**: 구매 후 교육 복귀 유도가 기본 CTA (구 문서의 "수첩으로 이동" 대체)

#### SHP-08 주문 내역
- **구성**: 주문 카드 목록(일자·상품·상태: 결제완료/배송중/배송완료/취소), [배송조회], 디지털 상품은 "지급 완료" 표시
- **상태**: 빈 내역 / 로딩
- **인터랙션**: 주문 탭 → 상세 시트(주문 정보·취소 요청 — 환불 정책은 §10 미확정, 확정 시 반영)

### 4.7 포인트

#### PNT-01 포인트 지갑
- **구성**: 보유 포인트 대형 표시, **소멸 예정 포인트 경고 카드**("30일 내 1,200P 소멸" — D21 선입선출·1년 유효), [충전하기], 내역 탭(전체/적립/사용/소멸), 원장 리스트(일시·사유: 시청/실습/퀴즈/완주보너스/충전/샵사용/문의권/환불/소멸 · 금액 · 잔액)
- **상태**: 내역 없음 / 무한 스크롤 로딩
- **인터랙션**: 소멸 경고 카드 탭 → 소멸 예정 상세(건별 만료일). [충전하기] → PNT-02

#### PNT-02 포인트 충전 (채널 분기, D15)
- **구성**: 충전 패키지 카드 목록(포인트량 + **현재 채널의 가격만** 표시), 보너스 포인트 뱃지(패키지별), 유의사항(유효기간 1년·환불 정책 링크)
- **상태**: 채널 감지 실패 시 안전측(IAP) 폴백 / 결제 진행 중 로딩 오버레이 / 실패 사유별 안내
- **인터랙션**:
  - 웹: 패키지 선택 → PortOne 결제창 → webhook 확인 폴링 → PNT-03
  - 앱: 패키지 선택 → shell IAP 브릿지 → 스토어 결제 시트 → 영수증 검증 → PNT-03
  - **금지**: 앱에서 웹 가격 표기·"웹에서 더 싸게" 류 문구·외부 결제 링크

#### PNT-03 충전 결과
- **구성(성공)**: 적립 연출, 충전 포인트/보너스, 갱신 잔액, [포인트샵 가기], [교육하러 가기]
- **구성(실패/지연)**: 사유, "결제는 됐는데 적립이 안 보여요" 지연 안내(webhook 처리 중), [재확인], 고객센터 링크
- **인터랙션**: 성공 후 지갑 잔액 즉시 반영

### 4.8 훈련사 Q&A

#### QNA-01 문의 목록
- **구성**: 보유 문의권 수 카드 + [문의권 구매](SHP-04), [새 문의 작성], 문의 카드 목록(썸네일·질문 요약·상태 뱃지: **답변 대기**(남은 SLA 시간)/**답변 완료**/**환불됨**)
- **상태**: 빈 목록 → 서비스 소개 + "훈련사에게 물어보세요" CTA / SLA 초과 환불 건은 환불 사유 표시
- **인터랙션**: 카드 탭 → QNA-03. [새 문의] → 문의권 보유 확인 → QNA-02 or 구매 유도 시트

#### QNA-02 문의 작성
- **구성**: 대상 강아지 선택, 분야 태그 선택(짖음/분리불안/배변 등), **영상 업로드**(file input capture — 촬영/앨범, 길이 ≤N분·용량 제한 안내, 업로드 진행률), 질문 텍스트(최소/최대 글자), 차감 안내("문의권 1개가 사용돼요"), [제출]
- **상태**: 업로드 중(진행률 + 백그라운드 이탈 경고) / 업로드 실패 재시도 / 길이·용량 초과 인라인 에러 / 임시저장(텍스트)
- **인터랙션**: 제출 → 차감 확인 다이얼로그 → 포인트(문의권) 차감 + 영상은 S3 업로드 → `video-postprocess` 큐 → QNA-01 복귀("답변 대기" + 48h 카운트다운)

#### QNA-03 문의 상세
- **구성**: 내 질문(영상 플레이어 + 텍스트), 상태 타임라인(접수→배정→답변), 훈련사 답변 섹션(프로필·텍스트/영상 답변), **별점 평가**(답변 열람 후 1회, 1~5점 + 선택 코멘트)
- **상태**: 답변 대기 → 남은 SLA 표시 / 환불됨 → 환불 안내 + 재문의 유도 / 답변 영상 처리 중 → "영상 준비 중"
- **인터랙션**: 답변 도착 푸시 → 딥링크로 본 화면 진입. 별점 제출 후 수정 불가(2차에서 노출 순위 반영)

### 4.9 알림

#### NTF-01 알림 센터
- **구성**: 알림 리스트(안읽음 상단·굵게 / 읽음), 타입별 아이콘(리마인드·포인트 소멸 예고·Q&A 답변·주문/배송·공지), 전체 읽음 처리
- **상태**: 빈 목록 / 로딩
- **인터랙션**: 알림 탭 → 해당 화면 딥링크(레슨·QNA-03·SHP-08·PNT-01 등) + 읽음 처리

### 4.10 마이 / 설정

#### MY-01 마이 홈
- **구성**: 프로필(계정), 포인트 요약 카드(잔액 + [지갑]/[충전]), 메뉴 리스트 — 강아지 관리(MY-02) / 훈련사 Q&A(QNA-01) / 주문 내역(SHP-08) / 데일리 목표·리마인드(MY-03) / 알림 설정(MY-04) / 재설문(설문 다시하기 → SUR-01) / 앱 설정(MY-05) / 공지·고객센터 / 로그아웃
- **인터랙션**: 각 메뉴 이동. 재설문 완료 시 추천 커리큘럼 갱신(기존 수강은 유지)

#### MY-02 강아지 프로필 관리
- **구성**: 등록 강아지 카드 목록(사진·이름·월령·학년), [강아지 추가](ONB-04 재사용 — 추가 시 해당 강아지 설문 유도), 카드 탭 → 프로필 수정 폼
- **상태**: 삭제(soft delete) 시 확인 다이얼로그("교육 기록도 함께 보관 처리돼요")
- **인터랙션**: 프로필 수정 시 월령 재계산. 다견 스위처 대상 목록과 동기화

#### MY-03 데일리 목표·리마인드 설정
- **구성**: 1일 레슨 목표 스테퍼, 리마인드 푸시 on/off + 시간대 피커, 오늘 목표 달성 현황
- **상태**: 웹 채널(푸시 불가) → 리마인드 항목에 앱 설치 안내
- **인터랙션**: 저장 즉시 반영. 목표 미달 시 설정 시간에 푸시 발송(`notification-dispatcher`)

#### MY-04 알림 설정
- **구성**: 마스터 토글, 카테고리별 토글(교육 리마인드 / 포인트 소멸 예고 / Q&A 답변 / 주문·배송 / 마케팅(선택 약관 연동)), iOS shell에서는 네이티브 알림 설정과 연동(D14)
- **상태**: OS 권한 거부 시 "기기 설정에서 허용" 안내 + 설정 이동
- **인터랙션**: 토글 즉시 저장

#### MY-05 앱 설정
- **구성**: 컬러 테마 선택(4종 스와치 — §5), 계정 관리(이메일/비밀번호 변경), 약관/개인정보처리방침, 버전 정보, 회원 탈퇴
- **상태**: 탈퇴 → 2단계 확인(보유 포인트·기록 소멸 안내) → soft delete
- **인터랙션**: 테마 변경 즉시 적용 + 영속화

## 5. 디자인 방향

`documents/design-theme-guide.md`의 **4색 테마 토큰 시스템(핑크·연두·민트·다크블루, accent/soft/gradient/shadow/ring + BASE 공통 토큰)**을 그대로 승계한다. 원문은 RN(`apps/mobile-app`) 기준으로 작성됐으나 RN이 폐기(D14)되었으므로, 동일 토큰을 `@waggle/design-tokens`에 정의하고 `apps/mobile-web`에서 Tailwind CSS 변수로 소비한다(색상값은 디자인 확정값 — 임의 수정 금지, 테마 선택 UI는 MY-05). 그 위에 얹는 톤은 **듀오링고식 밝고 캐릭터 중심**: 강아지 마스코트 캐릭터가 온보딩·빈 상태·축하 연출·리마인드 푸시의 화자로 일관되게 등장하고, 노드 맵·포인트 적립·배지·학년 승급 등 보상 순간마다 짧고 과장된 마이크로 애니메이션(콘페티, 펄스, 카운트업)으로 성취감을 극대화한다. 실패 상황(퀴즈 불통과, 레벨테스트 미통과)은 붉은 경고 대신 격려 프레이밍을 원칙으로 한다.
