# 기준정보 원본 및 DB 테이블 정의 보관소 (`.docs/data/`)

> 견종 코드표, 공통 코드, 교육 커리큘럼/상품 샘플(CSV/XLSX) 및 PostgreSQL 18 물리 테이블 정의서를 관리하는 단일 데이터 문서 폴더입니다.

## 관리 대상
- 견종(`breeds`), 공통 코드(`common_codes`), 배지/정책 초기 시드 데이터 샘플 (`*.csv`, `*.xlsx`, `*.json`)
- 교육 코스/레슨/포인트샵 초기 마스터 데이터 시트
- PostgreSQL 18 물리 DB 테이블 정의서 및 코드북 문서
